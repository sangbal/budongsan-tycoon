# Developer 스킬 그룹

## 개요

코드 작성, 파일 관리, 버전 제어, 자동 테스트를 담당합니다. 개발자의 핵심 작업 흐름을 지원합니다.

## 포함된 MCP 서버

### 1. **github**

- **용도**: 버전 제어, 협업, CI/CD
- **주요 기능**:
  - 저장소 검색 및 조회
  - 이슈 생성/수정/관리
  - Pull Request 생성/리뷰/병합
  - 브랜치 관리
  - Actions 워크플로우 트리거
  - 커밋 히스토리 조회
- **사용 시나리오**:
  - 코드 변경 후 PR 자동 생성
  - 버그 이슈 자동 작성
  - 배포 workflow 트리거
  - 팀 협업 관리

### 2. **filesystem**

- **용도**: 로컬 파일시스템 접근
- **주요 기능**:
  - 파일 읽기/쓰기
  - 디렉토리 생성/삭제
  - 파일 검색 (glob, grep)
  - 파일 이동/복사
  - 메타데이터 조회
- **사용 시나리오**:
  - 소스 코드 파일 수정
  - 설정 파일 생성/변경
  - 로그 파일 분석
  - 프로젝트 구조 탐색

### 3. **testsprite**

- **용도**: AI 기반 자동 테스트 및 디버깅
- **주요 기능**:
  - 단위 테스트 자동 생성
  - E2E 테스트 자동 생성
  - 코드 자동 수정
  - 버그 진단 및 해결
  - 테스트 실행 및 리포팅
- **사용 시나리오**:
  - 새로운 함수에 대한 테스트 자동 작성
  - 버그 발생 시 자동 수정 제안
  - 테스트 커버리지 자동 증대
  - 코드 품질 검증

## 연동 흐름

```
코드 수정 (filesystem)
   ↓
테스트 작성 (testsprite)
   ↓
테스트 실행 (testsprite)
   ↓
PR 생성 (github)
   ↓
CI/CD 실행 (github actions)
```

## 권한 설정

- ✅ 파일 읽기/쓰기 (로컬 개발)
- ✅ Git 저장소 접근 (버전 제어)
- ✅ 테스트 자동화 (코드 품질)
- ⚠️ GitHub Actions 트리거 (신중히 사용)
