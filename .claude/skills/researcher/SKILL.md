# Researcher 스킬 그룹

## 개요
웹 검색, 문서 조사, 브라우저 자동화를 통한 정보 수집 및 검증을 담당합니다.

## 포함된 MCP 서버

### 1. **brave-search**
- **용도**: 웹 검색, 최신 정보 조회
- **주요 기능**:
  - 웹 페이지 검색
  - 뉴스 검색
  - 이미지 검색
  - 비디오 검색
  - 로컬 검색 (비즈니스, 장소)
- **사용 시나리오**:
  - 최신 라이브러리/프레임워크 문서 조회
  - 기술 블로그 및 튜토리얼 검색
  - 버그 솔루션 찾기
  - API 문서 최신 정보 확인

### 2. **playwright**
- **용도**: 브라우저 자동화, UI 테스트, 스크린샷
- **주요 기능**:
  - 웹 페이지 자동 조작
  - 폼 입력 및 클릭
  - 스크린샷 및 동영상 녹화
  - 성능 메트릭 수집
  - 크로스 브라우저 테스트
- **사용 시나리오**:
  - E2E 테스트 작성 및 실행
  - 웹 UI 자동 검증
  - 서드파티 서비스 OAuth 흐름 테스트
  - 스크린샷 자동 생성

## 연동 방식
두 도구는 보완적으로 사용됩니다:
- `brave-search`로 정보 수집 → `playwright`로 실제 작동 확인
- 예: 특정 라이브러리 최신 문법 검색 → 실제 페이지 접속해서 동작 테스트

## 권한 설정
- ✅ 읽기 전용 (외부 정보 수집)
- ✅ 브라우저 상호작용 (자동화)
- ❌ 파일 쓰기 권한 제한 (별도 그룹에서 처리)
