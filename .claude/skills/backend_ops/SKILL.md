# Backend Ops 스킬 그룹

## 개요
백엔드 인프라 관리, 데이터베이스 운영, 에러 모니터링 및 애플리케이션 성능 관리를 담당합니다.

## 포함된 MCP 서버

### 1. **supabase**
- **용도**: 데이터베이스, 인증, 실시간 기능, 스토리지
- **주요 기능**:
  - PostgreSQL 데이터베이스 관리
  - 마이그레이션 적용 및 스키마 변경
  - 사용자 인증 (Auth) 설정
  - OAuth 제공자 설정
  - 스토리지 버킷 관리
  - RLS (Row Level Security) 정책
  - Edge Functions 배포
  - 실시간 구독 (Realtime)
- **사용 시나리오**:
  - 게임 저장 데이터 테이블 생성/수정
  - 사용자 인증 플로우 설정
  - 리더보드 데이터 분석
  - 클라우드 저장 기능 구현
  - Edge Function 배포

### 2. **sentry**
- **용도**: 에러 추적, 성능 모니터링, 문제 관리
- **주요 기능**:
  - 에러 및 예외 추적
  - 성능 모니터링 (트랜잭션, 스팬)
  - 세션 재생 및 분석
  - 이슈 그룹화 및 우선순위
  - 릴리스 추적
  - 알림 및 통합 설정
  - 에러 패턴 분석
  - 사용자 피드백 수집
- **사용 시나리오**:
  - 프로덕션 에러 모니터링
  - 게임 성능 병목 지점 파악
  - 사용자별 에러 패턴 분석
  - 배포 후 안정성 검증
  - 느린 API 호출 식별

## 연동 흐름

```
Supabase (데이터 저장)
   ↓
애플리케이션 (게임 실행)
   ↓
Sentry (에러/성능 수집)
   ↓
모니터링 & 알림
```

## 사용 사례

### 데이터 관리 (Supabase)
```
1. 마이그레이션으로 새 테이블 생성
2. RLS 정책으로 보안 설정
3. Edge Function으로 비즈니스 로직 구현
4. 클라이언트 SDK로 데이터 쿼리
```

### 에러 추적 (Sentry)
```
1. 프로덕션 배포 후 에러 수집
2. 에러 패턴 분석
3. 원인 파악 및 수정
4. 배포 후 재발 모니터링
```

## 권한 설정
- ✅ 데이터베이스 읽기/쓰기 (Supabase)
- ✅ 마이그레이션 적용 (스키마 변경)
- ✅ 에러 조회 및 관리 (Sentry)
- ⚠️ 알림 설정 (신중히 사용)
- ❌ 프로덕션 데이터 삭제 (보호됨)
