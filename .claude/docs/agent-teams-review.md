# Agent Teams 검토 기록

> 검토일: 2026-02-07
> 결정: **현상 유지** (선택지 A) + 하이브리드 패턴 적용 (선택지 C)

## 배경

Claude Code에 **Agent Teams** 실험적 기능이 추가됨. 현재 프로젝트의 Task tool 기반 subagent 패턴(CEO -> 전문가 위임)과의 차이를 분석하고 반영 여부를 결정.

## Agent Teams vs 현재 방식 비교

| 항목      | Subagent (현재) | Agent Teams                |
| --------- | --------------- | -------------------------- |
| 통신      | CEO 경유만 가능 | 팀원 간 직접 메시지        |
| 컨텍스트  | 요약 반환       | 독립 컨텍스트              |
| 조율      | CEO가 전부 관리 | 공유 작업 목록 + 자체 조율 |
| 위임 모드 | CLAUDE.md 규칙  | 시스템 레벨 강제           |
| 토큰 비용 | 낮음            | 높음                       |
| 안정성    | 정식 기능       | 실험적                     |

## 현상 유지 사유

1. **실험적 기능**: 알려진 제한사항이 다수 (세션 재개 불가, 동기화 지연 등)
2. **Windows 미지원**: split-pane 모드 사용 불가 (프로젝트 환경이 Windows)
3. **비용 효율**: subagent 방식이 토큰 비용이 훨씬 낮음
4. **안정성**: 현재 방식이 이미 잘 동작 중
5. **현재 구조 충분**: CLAUDE.md 기반 조직 구조가 Agent Teams의 핵심 개념을 이미 구현

## 적용한 하이브리드 패턴 (선택지 C)

Agent Teams에서 배운 모범사례를 현재 subagent 방식에 적용:

1. **공유 작업 목록 패턴**: CEO가 TaskCreate/TaskList를 적극 활용하여 작업 추적
2. **계획 승인 패턴**: 위험 작업은 plan mode를 통해 회장 승인 후 구현
3. **작업 크기 가이드**: 전문가당 5-6개 이하 작업 배정

## 재검토 기준

다음 조건이 충족되면 Agent Teams 재검토:

- [ ] Agent Teams가 정식 기능으로 승격 (실험적 딱지 제거)
- [ ] Windows split-pane 지원 추가
- [ ] 세션 재개(`/resume`) 시 팀원 복원 지원
- [ ] 토큰 비용 최적화 (현재 대비 합리적 수준)
