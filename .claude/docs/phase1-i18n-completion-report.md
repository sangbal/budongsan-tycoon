## Phase 1 목표 및 범위

### 목표

Phase 1은 SeoulSurvival 게임의 다국어 지원 기반을 확립하기 위한 프로젝트입니다. 현재 하드코딩된 텍스트를 모두 i18n 시스템으로 전환하고, 번역 검증 자동화를 통해 향후 언어 추가 시 품질을 보장합니다.

### 범위

- 하드코딩된 UI 텍스트의 i18n 전환
- 번역 키 통합 및 일관성 유지
- 번역 검증 스크립트 개발
- 문서 업데이트 및 개발 가이드 작성

### Step 1.5: 번역 검증 스크립트 개발

**파일**: `scripts/validate-i18n.js`

**기능**:

1. **키 일치 검증** - ko.js와 en.js의 모든 키가 완벽하게 일치하는지 확인
2. **중복 키 검출** - 각 언어 파일에서 중복된 키가 있는지 검사
3. **매개변수 검증** - `{param}` 형식의 매개변수가 모든 언어에서 일치하는지 확인
4. **HTML 참조 검증** - HTML `data-i18n` 속성의 모든 키가 유효한지 검증
5. **JavaScript 참조 검증** - 코드의 `t('key')` 호출이 유효한 키를 사용하는지 검증
6. **상세 보고서** - 발견된 문제를 카테고리별로 정렬하여 출력

**성능**: ~50ms (작은 프로젝트 기준)

---

### Step 1.6: npm script 추가

**파일**: `package.json`

**추가된 명령어**:

```json

```

**사용법**:


**통합**:

## 기술 구현 세부사항

### i18n 시스템 구조

```
seoulsurvival/src/i18n/
├── index.js                 # t(key), setLang() API
└── translations/
    ├── ko.js               # 한국어 (952개 키)
    └── en.js               # 영어 (952개 키)
```

### 번역 키 네이밍 규칙

- **카테고리**: `category.subcategory.item`
- **예시**: `settings.autoSave`, `auth.login`, `ui.income`
- **매개변수**: `{varName}` 형식 (예: `"Welcome, {name}"`)

### 검증 자동화 통합

**현재**:

- 수동 검증: `npm run validate:i18n`
- 개발 중 QA 확인

**예정 (Phase 2)**:

- Pre-commit hook 자동 검증
- GitHub Actions CI/CD 통합
- 배포 전 필수 체크
