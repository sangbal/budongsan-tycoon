## 1. CEO 에이전트 (ceo.md) 최적화

### 1.1 제거할 섹션 (줄 번호)

| 섹션                   | 줄 번호 | 이유                              |
| ---------------------- | ------- | --------------------------------- |
| `## 보고 형식`         | 82-103  | 불필요하게 상세, 실사용 빈도 낮음 |
| `## 하위 C-level 목록` | 106-118 | CLAUDE.md와 중복                  |

### 1.2 수정할 섹션

**`## 의사결정 프로세스` (29-43줄) → `## 필수 워크플로우`로 변경**

```markdown
## 필수 워크플로우 (반드시 준수)

### 1단계: AskUserQuestion (모든 요청에 필수)
```

[스티브 요청 수신]
│
└─→ AskUserQuestion 사용 - 요청의 목적/범위 확인 - 우선순위 확인 - 제약사항 확인

```

### 2단계: 키워드 기반 라우팅
| 키워드 | C-level | 예시 |
|--------|---------|------|
| 버그, 개발, 테스트, 빌드 | CTO | "로그인 버그 수정" |
| 밸런스, 기획, 업적, 스토리 | CPO | "프레스티지 밸런스" |
| UI, UX, 디자인, 레이아웃 | CMO | "모바일 UI 개선" |
| 시장, 경쟁사, 트렌드 | CSO | "클리커 시장 분석" |
| 보안, 장애, 모니터링 | CRO | "Sentry 에러 확인" |
| 공지, 릴리스, 문서 | CCO | "릴리스 노트 작성" |
| 라이선스, 약관 | CLO | "라이선스 검토" |
| 에이전트, 조직 | CHRO | "새 에이전트 필요" |

### 3단계: Task 호출 및 결과 종합
- 단일 C-level 해당 시: 직접 라우팅
- 복합 요청 시: 병렬 호출 후 결과 종합
```

### 1.3 간소화할 섹션

**`## 에이전트 생성 요청 처리` (64-79줄)**

- 현재: 16줄
- 변경: 5줄로 축소 (CHRO에게 위임 명시만)

### 1.4 예상 결과

- Before: 118줄
- After: ~70줄 (약 40% 감소)
