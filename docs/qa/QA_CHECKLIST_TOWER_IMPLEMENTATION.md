# QA 체크리스트: 서울타워 구현 및 엔딩 시스템

## 📋 테스트 범위

### 1. 서울타워 구매 기능

#### 기본 기능

- [ ] 서울타워 카드가 투자 탭 부동산 섹션에 표시됨
- [ ] 서울타워 카드가 초기에는 잠금 상태 (회색 처리)
- [ ] 서울타워 가격이 "1조원 (고정)"으로 표시됨
- [ ] CEO 달성 + 빌딩 1개 이상 시 서울타워 해금 메시지 표시
- [ ] 해금 후 서울타워 카드가 정상 색상으로 표시됨

#### 구매 조건

- [ ] 1조원 이상 보유 시 서울타워 구매 버튼 활성화
- [ ] 1조원 미만 시 구매 불가 메시지 표시 ("💸 자금이 부족합니다")
- [ ] 서울타워 구매 시 현금 1조원 차감 확인
- [ ] 서울타워 구매 후 towers 변수 +1 증가 확인

#### UI 상태

- [ ] 구매 모드에서만 서울타워 구매 버튼 활성화
- [ ] 판매 모드에서 서울타워 구매 버튼 비활성화
- [ ] 잠금 상태일 때 적절한 스타일 적용 (회색, pointer-events: none)

---

### 2. 엔딩 팝업 및 축하 효과

#### 엔딩 팝업 표시

- [ ] 서울타워 구매 시 엔딩 팝업이 즉시 표시됨
- [ ] 팝업 제목: "🎉 서울타워 완성"
- [ ] 팝업 아이콘: 🗼
- [ ] 팝업 메시지에 다음 내용 포함:
  - [ ] "🗼 서울타워 완성 🗼"
  - [ ] "알바에서 시작해 CEO까지..."
  - [ ] "리더보드에 기록되었습니다: 🗼x1"
  - [ ] "✨ 프레스티지 시스템 ✨" 설명
  - [ ] 타워 개수 누적 설명
  - [ ] 리더보드 순위 상승 설명

#### 버튼

- [ ] 확인 버튼 텍스트: "🔄 새로운 시작하기"
- [ ] 취소 버튼이 숨겨져 있음 (display: none)
- [ ] 확인 버튼 클릭 시 게임 리셋 확인

#### 축하 효과

- [ ] 엔딩 팝업 표시 시 서울타워 이모지(🗼)가 하늘에서 떨어짐
- [ ] 약 30개의 이모지가 떨어짐
- [ ] 이모지가 좌우로 흔들리며 떨어짐 (꽃잎 효과)
- [ ] 이모지 크기가 적절함 (2em)
- [ ] 이모지가 모달 위에 표시됨 (z-index: 9999)
- [ ] 애니메이션이 3초 동안 지속됨
- [ ] 애니메이션 완료 후 요소가 제거됨

---

### 3. 게임 리셋 및 프레스티지

#### 게임 리셋

- [ ] "🔄 새로운 시작하기" 버튼 클릭 시 게임 리셋
- [ ] 리셋 시 모든 자산이 0으로 초기화됨
- [ ] 리셋 시 커리어가 초기 상태로 돌아감
- [ ] 리셋 시 업적이 모두 잠금 상태로 돌아감
- [ ] 리셋 시 일기장에 "🗼 새로운 시작. 다시 한 번." 메시지 기록

#### 프레스티지 시스템

- [ ] 게임 리셋 후에도 towers 변수가 유지됨
- [ ] 저장/로드 시 towers 값이 정상적으로 저장/복원됨
- [ ] 두 번째 타워 구매 시 towers가 2로 증가함
- [ ] 리더보드에 타워 개수가 누적되어 표시됨 (현재는 updateLeaderboard 함수 수정 필요)

---

### 4. 리더보드 연동

#### 리더보드 업데이트

- [ ] 서울타워 구매 시 리더보드 업데이트 시도
- [ ] 닉네임이 있을 때만 리더보드 업데이트
- [ ] 리더보드 업데이트 실패 시에도 게임 진행에 영향 없음
- [ ] 콘솔에 "리더보드: 서울타워 구매 후 업데이트 완료 (타워 X개)" 로그 출력

#### 알려진 제한사항

- [ ] 현재 updateLeaderboard 함수가 towerCount 파라미터를 받지 않음
- [ ] 리더보드에 타워 개수가 저장되지 않음 (추후 수정 필요)

---

### 5. 저장/로드

#### 저장

- [ ] 서울타워 구매 후 saveGame() 호출 시 towers 값이 저장됨
- [ ] 저장 데이터에 towers 필드가 포함됨

#### 로드

- [ ] 게임 로드 시 towers 값이 정상적으로 복원됨
- [ ] towers 값이 없을 때 기본값 0으로 처리됨

---

### 6. 일기장 기록

- [ ] 서울타워 구매 시 일기장에 다음 메시지 기록:
  - [ ] "🗼 서울타워 완성."
  - [ ] "서울의 정상에 도달했다."
  - [ ] "이제야 진짜 시작인가?"

### 7. 해금 시스템

#### 해금 조건

- [ ] CEO 달성 (careerLevel >= 9) 확인
- [ ] 빌딩 1개 이상 보유 확인
- [ ] 두 조건을 모두 충족해야 해금됨

#### 해금 메시지

- [ ] 빌딩 구매 후 서울타워 해금 메시지 표시: "🔓 서울타워가 해금되었습니다!"
- [ ] 해금 메시지가 중복으로 표시되지 않음

---

### 8. UI 업데이트

#### 가격 표시

- [ ] 서울타워 가격이 항상 "1조"로 표시됨
- [ ] 가격이 변하지 않음 (고정 가격)

#### 잠금 상태 표시

- [ ] 해금 전: 회색 처리, 클릭 불가
- [ ] 해금 후: 정상 색상, 클릭 가능

---

### 9. 에러 처리

- [ ] 자금 부족 시 명확한 에러 메시지 표시
- [ ] 해금 조건 미충족 시 명확한 에러 메시지 표시
- [ ] 리더보드 업데이트 실패 시 게임 진행에 영향 없음
- [ ] 예외 발생 시 콘솔에 에러 로그 출력

---

### 10. 성능

- [ ] 축하 효과가 성능에 큰 영향을 주지 않음
- [ ] 30개의 이모지가 떨어져도 프레임 드롭 없음
- [ ] 애니메이션 완료 후 메모리 누수 없음 (요소 제거 확인)

## 🐛 발견된 문제

### 수정 필요

1. **리더보드 타워 개수 저장**: `updateLeaderboard` 함수에 `towerCount` 파라미터 추가 필요
2. **리더보드 UI 타워 개수 표시**: 리더보드에 타워 개수(🗼x3) 표시 기능 추가 필요

### 확인 필요

- [ ] 실제 게임 플레이 테스트
- [ ] 브라우저 콘솔 오류 확인
- [ ] 모바일 환경 테스트
- [ ] 다양한 브라우저 호환성 테스트

## 📝 테스트 시나리오

### 시나리오 1: 서울타워 해금 및 구매

1. 게임 시작
2. CEO 달성 (약 15,000 클릭)
3. 빌딩 1개 구매
4. 서울타워 해금 메시지 확인
5. 1조원 모으기
6. 서울타워 구매
7. 엔딩 팝업 확인
8. 축하 효과 확인 (🗼 이모지 떨어짐)
9. "🔄 새로운 시작하기" 버튼 클릭
10. 게임 리셋 확인
11. towers 값이 유지되는지 확인

### 시나리오 2: 프레스티지 시스템

1. 타워 1개 구매 → 게임 리셋
2. 다시 CEO 달성 및 빌딩 구매
3. 다시 타워 1개 구매
4. towers 값이 2인지 확인
5. 저장/로드 후 towers 값 유지 확인

### 시나리오 3: 축하 효과

1. 서울타워 구매
2. 엔딩 팝업 표시 확인
3. 동시에 🗼 이모지가 하늘에서 떨어지는지 확인
4. 이모지가 좌우로 흔들리며 떨어지는지 확인
5. 약 3초 동안 지속되는지 확인
