## 🔍 테스트 체크리스트

### 기본 기능 테스트

- [ ] 게임 로드 시 오류 없음
- [ ] 서울타워 카드가 투자 섹션에 표시됨

- [ ] 빌딩 구매 후 서울타워 해금 메시지 표시

### 가격/구매 테스트

- [ ] 서울타워 가격이 항상 1조원으로 표시됨 (가격 성장 없음)

- [ ] 1조원 미만 시 구매 불가 메시지 표시

- [ ] 서울타워는 판매 불가 (판매 모드에서 버튼 비활성화)

### 엔딩/프레스티지 테스트

- [ ] 타워 구매 후 리더보드 업데이트 (타워 개수 포함)

## 📝 테스트 시나리오

### 시나리오 1: 서울타워 해금 및 구매

1. 게임 시작
2. CEO 달성 (15,000 클릭)
3. 빌딩 1개 구매
4. 서울타워 해금 메시지 확인
5. 1조원 모으기
6. 서울타워 구매
7. 엔딩 모달 확인
8. 리더보드 확인 (🗼x1 표시)

### 시나리오 2: 리더보드 순위

1. 타워 1개 달성
2. 자산 100조원 달성
3. 타워 0개, 자산 200조원인 계정과 비교
4. 타워 1개인 계정이 위에 표시되는지 확인

### 시나리오 3: 판매 환급률

1. 예금 10개 구매
2. 예금 10개 판매
3. 구매 금액과 판매 금액이 동일한지 확인 (100% 환급)

### 시나리오 4: 가격 성장률

1. 예금 1개 구매 (5만원)
2. 예금 1개 추가 구매
3. 두 번째 예금 가격이 5만원 × 1.05 = 5.25만원인지 확인

## ⚠️ 주의사항

1. **Supabase 스키마 업데이트 필수**: `supabase/leaderboard.sql`을 Supabase SQL Editor에서 실행해야 함
2. **타워는 판매 불가**: 판매 모드에서도 구매만 가능
3. **타워 달성 후**: 자산 변화는 리더보드에 반영되지 않음 (구매 시점 자산으로 고정)
4. **엔딩 후**: 게임은 계속 진행 가능하나, 리더보드는 업데이트되지 않음
