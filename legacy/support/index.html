시작하기

플레이는 누구나 가능한가요?

네, 로그인 없이도 플레이할 수 있습니다. 게스트 모드로 플레이하면 브라우저에 로컬 저장이 됩니다.

로그인하면 클라우드 저장과 기기 간 동기화가 가능합니다. 여러 기기에서 같은 계정으로 접속하면 진행 상황을 이어갈 수 있습니다.

로그인하면 무엇을 할 수 있나요?

로그인 시 다음 기능을 사용할 수 있습니다:

  • 클라우드 저장: 여러 기기에서 진행 상황 동기화
  • 리더보드 참여: 글로벌 랭킹에 닉네임으로 참여
  • 업적 기록: 업적이 계정에 저장되어 유지

로그인은 Google 계정으로 간단하게 할 수 있습니다.

저장 & 동기화

로컬 저장과 클라우드 저장의 차이는 무엇인가요?

로컬 저장 (비로그인):

  • 브라우저의 LocalStorage에 저장
  • 5초마다 자동 저장
  • 같은 브라우저/기기에서만 접근 가능
  • 브라우저 데이터 삭제 시 저장 데이터도 삭제됨

클라우드 저장 (로그인):

  • Supabase 서버에 저장
  • 로컬 저장(5초마다) + 클라우드 저장(탭 닫기 시 자동 플러시)
  • 어떤 기기에서든 로그인하면 접근 가능
  • 계정 삭제 전까지 데이터 유지
로그인/로그아웃 시 저장은 어떻게 되나요?

로그인 시:

  • 기존 로컬 저장 데이터가 있으면 클라우드에 업로드됩니다
  • 이후부터는 로컬 + 클라우드 이중 저장이 됩니다

로그아웃 시:

  • 클라우드 저장은 중단되지만, 로컬 저장은 계속됩니다
  • 다시 로그인하면 클라우드 저장이 재개됩니다
저장 데이터를 수동으로 백업할 수 있나요?

현재는 자동 저장만 지원합니다. 수동 백업 기능은 추후 추가될 예정입니다.

로그인 사용자는 클라우드에 자동 저장되므로 별도 백업이 필요 없습니다.

업적 & 리더보드

닉네임은 어떻게 설정하나요?

게임 내 설정 탭에서 닉네임을 설정할 수 있습니다. 닉네임은:

  • 1~6자 (한글/영문/숫자/밑줄만 허용)
  • 전역 유니크 (다른 유저와 중복 불가)
  • 30초 쿨타임 (스팸 방지)
  • 로그인 필수 (리더보드 참여용)
닉네임이 중복된다고 나옵니다

닉네임은 대소문자 구분 없이 비교됩니다. 예를 들어 "Steve"와 "steve"는 동일한 것으로 간주됩니다.

다른 유저가 이미 사용 중인 닉네임은 사용할 수 없습니다. 다른 닉네임을 시도해주세요.

리더보드에 반영되는 타이밍은 언제인가요?

리더보드는 다음 시점에 업데이트됩니다:

  • 게임 저장 시 30초마다 자동 업데이트 (닉네임이 있을 때만)
  • 첫 타워 구매 후에는 자동 업데이트가 중단됩니다
  • 랭킹 탭에서 수동으로 조회할 수 있습니다

계정 & 데이터

데이터 삭제와 계정 삭제의 차이는 무엇인가요?

데이터 삭제 (내 데이터 삭제):

  • 클라우드 저장 데이터와 리더보드 기록만 삭제
  • 계정은 유지 (다시 로그인 가능)
  • 로컬 저장도 함께 초기화됨
  • 닉네임은 회수되어 다른 유저가 사용 가능

계정 삭제 (회원 탈퇴):

  • Supabase 계정 자체가 삭제됨
  • 모든 데이터 삭제 (저장, 리더보드, 닉네임 등)
  • 되돌릴 수 없음
  • 다시 로그인 불가 (새 계정 생성 필요)

⚠️ 주의: 계정 삭제는 되돌릴 수 없는 작업입니다. 신중하게 결정해주세요.

정말 삭제가 필요한가요?

데이터 삭제나 계정 삭제 전에 다음을 고려해보세요:

  • 게임을 새로 시작하고 싶다면: 설정 탭의 "게임 새로 시작" 버튼 사용
  • 진행 상황만 초기화하고 싶다면: 데이터 삭제 (계정 유지)
  • 완전히 탈퇴하고 싶다면: 계정 삭제

더 자세한 안내는 계정 관리 페이지를 참고하세요.

계정 삭제 후에도 로컬 저장 데이터가 남아있나요?

계정 삭제 시 클라우드 데이터는 즉시 삭제되지만, 브라우저의 로컬 저장 데이터는 자동으로 삭제되지 않습니다.

완전히 초기화하려면 브라우저의 개발자 도구에서 LocalStorage를 수동으로 삭제해야 합니다.
