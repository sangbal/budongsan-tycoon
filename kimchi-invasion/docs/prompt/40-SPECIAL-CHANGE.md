# 방향 전환 프롬프트

> **용도:** 계획 변경, 우선순위 조정
> **사용 시점:** 기존 계획을 수정해야 할 때
> **권장 Agent:** gdd-enhancer, game-director, orchestrator

---

## 프롬프트 - 우선순위 변경 (아래 내용 전체 복사)

```
개발 우선순위를 변경해줘.

변경 사유:
[왜 변경이 필요한지]

새로운 우선순위:
1. [가장 먼저 할 것]
2. [그 다음 할 것]
3. [나중에 할 것]

PROGRESS.md의 체크리스트를 새로운 우선순위에 맞게 재정렬해줘.
개발 계획서(development-plan.md)도 필요하면 업데이트해줘.
```

---

## 프롬프트 - 기능 스킵 (아래 내용 전체 복사)

```
[기능명]을 일단 스킵하고 다음으로 진행해줘.

스킵 사유:
[왜 스킵하는지]

PROGRESS.md에:
1. 해당 항목을 "스킵됨" 또는 "Cut List"로 표시
2. 스킵 사유 기록
3. 다음 작업으로 이동

나중에 다시 볼 수 있도록 기록해줘.
```

---

## 프롬프트 - 설계 변경 (아래 내용 전체 복사)

```
[시스템/기능]의 설계를 변경해줘.

현재 설계:
[현재 어떻게 되어있는지]

변경할 설계:
[어떻게 바꾸고 싶은지]

변경 사유:
[왜 바꾸는지]

관련 파일들 모두 확인하고 일관성 있게 변경해줘.
변경 내용을 PROGRESS.md 작업 로그에 기록해줘.
```

---

## 사용 예시

### 기능 축소

```
M2 컨베이어 시스템을 일단 스킵하고 다음으로 진행해줘.

스킵 사유:
시간이 부족해서 M1 완성에 집중하려고 함

PROGRESS.md에:
1. 해당 항목을 "스킵됨" 또는 "Cut List"로 표시
2. 스킵 사유 기록
3. 다음 작업으로 이동

나중에 다시 볼 수 있도록 기록해줘.
```

### 기술 변경

```
카메라 시스템의 설계를 변경해줘.

현재 설계:
직접 구현한 팬/줌 시스템

변경할 설계:
PixiJS Viewport 플러그인 사용

변경 사유:
직접 구현보다 안정적이고 빠름

관련 파일들 모두 확인하고 일관성 있게 변경해줘.
변경 내용을 PROGRESS.md 작업 로그에 기록해줘.
```

## 프롬프트 - gdd-enhancer 활용 (권장)

```
gdd-enhancer를 사용해서 개발 방향을 조정해줘.

변경 내용:
[무엇을 바꾸려는지]

변경 사유:
[왜 바꾸는지]

gdd-enhancer가:
1. 현재 GDD/PROGRESS.md 분석
2. 변경이 다른 시스템에 미치는 영향 확인
3. 문서 업데이트 (PROGRESS.md, development-plan.md)
4. Cut List 관리
5. 일관성 검토

결과 보고해줘.
```

---

## 프롬프트 - 대규모 방향 전환 (orchestrator)

```
orchestrator를 사용해서 대규모 방향 전환을 진행해줘.

변경 내용:
[전체 변경 계획]

orchestrator가:
1. game-director로 변경 타당성 검토
2. gdd-enhancer로 문서 업데이트
3. quality-agent로 기존 코드 영향 분석
4. test-agent로 테스트 업데이트
5. PROGRESS.md 체크리스트 재정렬

단계별로 진행하면서 결과 보고해줘.
```

---

## 변경 이력 관리

변경 시 PROGRESS.md 작업 로그에 기록:

```markdown
### 2026-01-XX

- [x] 기존 작업들...
- **[변경]** 컨베이어 시스템 → Cut List 이동 (사유: M1 우선)
- **[변경]** 카메라 구현 방식 변경 (직접구현 → Viewport)
```

## Agent 역할 분담

| 변경 유형           | Agent         |
| :------------------ | :------------ |
| 문서/계획 업데이트  | gdd-enhancer  |
| 방향성 결정         | game-director |
| 대규모 변경 조율    | orchestrator  |
| 기존 코드 영향 분석 | quality-agent |
| 테스트 업데이트     | test-agent    |

## Ralph Loop 연동 (자동 정리)

```
/ralph-loop "
방향 전환 자동 정리:

변경: [변경 내용]

1. PROGRESS.md 체크리스트 업데이트
2. Cut List 정리
3. 관련 문서 일관성 확인
4. npm run lint 실행
5. 모든 문서 정리 완료 시 <promise>CHANGE_DONE</promise>
" --max-iterations 10 --completion-promise "CHANGE_DONE"
```
