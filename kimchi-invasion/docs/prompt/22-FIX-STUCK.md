# 막힘 상황 해결 프롬프트

> **용도:** 진행이 안 될 때 대안 탐색
> **사용 시점:** 여러 번 시도해도 해결이 안 될 때
> **권장 Agent:** game-director, orchestrator

---

## 프롬프트 - 기본 (아래 내용 전체 복사)

```
현재 작업에서 막혔어.

상황:
[무엇을 하려고 했는지]

시도한 것:
[이미 시도해본 방법들]

문제:
[왜 안 되는지, 어디서 막혔는지]

다음 중 하나로 해결해줘:
1. 다른 접근 방식 제안
2. 우회 방법 찾기
3. 임시 해결책으로 일단 진행
4. 해당 작업 스킵하고 다음으로

어떤 방식이 좋을지 추천해주고 바로 진행해.
```

---

## 프롬프트 - game-director 활용 (권장)

```
game-director를 사용해서 막힌 문제를 분석해줘.

상황:
[무엇을 하려고 했는지]

시도한 것:
[이미 시도해본 방법들]

문제:
[왜 안 되는지]

game-director가:
1. 벤치마크 게임들에서 유사 문제 해결 사례 조사
2. Context7로 관련 라이브러리 문서 확인
3. 대안적 접근 방식 3가지 제안
4. 각 방식의 장단점 분석
5. 최적 방식 추천 및 구현 계획

결과를 바탕으로 진행 방향 결정해줘.
```

---

## 프롬프트 - Context7 + Brave Search 활용

```
막힌 문제 해결을 위해 조사해줘.

문제:
[구체적 기술 문제]

Context7으로:
1. 관련 라이브러리 공식 문서 검색
2. Best Practice 확인
3. 알려진 이슈/해결책 확인

Brave Search로:
1. 최신 해결 사례 검색
2. 커뮤니티 논의 확인
3. 대안 라이브러리/방법 조사

조사 결과를 바탕으로 해결책 제시하고 구현해줘.
```

## 프롬프트 - 복합 문제 (orchestrator)

```
orchestrator를 사용해서 복합적인 막힘 상황을 해결해줘.

상황:
[문제 상황 설명]

orchestrator가:
1. game-director로 벤치마크 분석
2. Context7로 기술 문서 확인
3. bug-hunter로 근본 원인 분석
4. 대안 접근법 우선순위화
5. 최적 방안으로 구현 진행

단계별로 진행하면서 결과 보고해줘.
```

## 막힘 유형별 대응

| 막힘 유형         | 권장 Agent/MCP           | 권장 대응                         |
| :---------------- | :----------------------- | :-------------------------------- |
| 라이브러리 호환성 | Context7 + game-director | 대안 라이브러리 또는 직접 구현    |
| 복잡한 설계       | game-director            | 단순화된 MVP 버전으로 시작        |
| 성능 문제         | performance-agent        | 임시로 기능 제한, 최적화는 나중에 |
| 원인 불명         | bug-hunter + Playwright  | 최소 재현 케이스 만들어서 분석    |
| 시간 부족         | gdd-enhancer             | Cut List에 추가하고 다음으로      |
| 기술 정보 부족    | Context7 + Brave Search  | 최신 문서/사례 조사               |

## Ralph Loop 연동 (자동 해결)

```
/ralph-loop "
막힌 문제 자동 해결:

문제: [구체적 문제]

1. Context7로 관련 문서 확인
2. 해결책 시도
3. npm run test:unit 실행
4. 실패하면 다른 접근법 시도
5. Playwright로 동작 확인
6. 모든 테스트 통과 시 <promise>STUCK_RESOLVED</promise>
" --max-iterations 20 --completion-promise "STUCK_RESOLVED"
```
