# 세션 체크포인트 프롬프트

> **용도:** 작업 중단 전 진행 상황 저장
> **사용 시점:** 세션 종료 전, 긴 휴식 전
> **권장 Agent:** gdd-enhancer

---

## 프롬프트 - 기본 (아래 내용 전체 복사)

```
작업을 중단하기 전에 현재 상태를 저장해줘.

1. PROGRESS.md 업데이트:
   - 완료된 항목 체크 표시
   - 현재 진행 중인 항목 상태
   - 다음에 이어서 할 작업 명시

2. 작업 로그 추가:
   - 오늘 날짜로 완료한 작업 목록
   - 발생한 이슈나 메모

3. 미완료 작업이 있다면:
   - 어디까지 진행했는지
   - 다음에 뭘 해야 하는지 구체적으로 기록

4. 수정한 파일 목록 정리

마지막으로 다음 세션에서 바로 시작할 수 있는 한 줄 요약을 알려줘.
```

---

## 프롬프트 - gdd-enhancer 활용 (권장)

```
gdd-enhancer를 사용해서 세션 체크포인트를 저장해줘.

gdd-enhancer가:
1. PROGRESS.md 완료/진행 중 항목 업데이트
2. 작업 로그에 오늘 날짜 기록 추가
3. 미완료 작업 상세 기록
4. 관련 문서 일관성 확인
5. 다음 세션 시작점 명시

다음 세션에서 바로 시작할 수 있는 한 줄 요약 알려줘.
```

---

## 예상 결과

1. PROGRESS.md가 최신 상태로 업데이트됨
2. 작업 로그에 오늘 날짜 기록 추가
3. 다음 세션 시작 시 즉시 작업 재개 가능
