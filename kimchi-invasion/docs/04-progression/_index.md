## 🎯 빠른 참조

### Multi-Layer Loop Architecture

| 루프         | 주기            | 주요 활동         | 보상 유형      |
| :----------- | :-------------- | :---------------- | :------------- |
| **Tick**     | 50ms            | 물리 시뮬레이션   | 시각적 만족    |
| **Micro**    | 3-10초          | 단일 건물 배치    | 즉각 피드백    |
| **Core**     | 10-30분         | 생산라인 완성     | 목표 달성 보상 |
| **Session**  | 3-6시간         | 마일스톤 달성     | 해금 + 업적    |
| **Meta**     | ~50시간 (1회차) | 프레스티지        | 영구 보너스    |
| **Infinite** | 무제한          | 메가베이스/최적화 | 리더보드       |

### 마일스톤 요약

| 마일스톤 | 해금 조건             | 완료 조건       | MVP |
| :------- | :-------------------- | :-------------- | :-: |
| **M1**   | 게임 시작             | 김치 10캔 생산  | ✅  |
| **M2**   | M1 + 🔬×15            | 분당 10캔       | ✅  |
| **M3**   | M2 + 🧬×20            | 3종 + 분당 50캔 | 🔜  |
| **M4**   | M3 + 🧬×50 + 첫 수출  | 총 $100,000     | 🔜  |
| **M5**   | M4 + 🧫×40 + $500,000 | 우주선 발사     | 🔜  |

### 우주선 등급 (Loadout)

| 등급   | 슬롯 | 비용       | 용도            |
| :----- | :--- | :--------- | :-------------- |
| 기본형 | 3개  | $100,000   | 빠른 프레스티지 |
| 중형   | 5개  | $500,000   | 균형 잡힌 선택  |
| 대형   | 8개  | $2,000,000 | 거의 모든 기술  |

### 프레스티지 보너스 (주요)
