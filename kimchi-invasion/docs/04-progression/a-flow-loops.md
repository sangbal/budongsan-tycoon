## 4.1. 게임 철학: Flow State Engineering

### 4.1.1. 심리학적 기반

**Csikszentmihalyi의 Flow 이론** 기반 게임 설계:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         FLOW STATE DIAGRAM                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Challenge                                                                  │
│  (도전)                                                                     │
│     ▲                                                                       │
│     │                    ┌───────────────┐                                 │
│     │    불안 영역       │   FLOW ZONE   │                                 │
│     │   (Anxiety)        │  (몰입 상태)  │                                 │
│     │                    │               │                                 │
│     │                    │  ★ 최적 경험  │                                 │
│     │                    │               │                                 │
│     │                    └───────────────┘                                 │
│     │                                         지루함 영역                   │
│     │                                         (Boredom)                    │
│     │                                                                       │
│     └──────────────────────────────────────────────────────────► Skill    │
│                                                                 (기술)     │
│                                                                             │
│  ★ 핵심: 플레이어 기술이 증가하면 도전도 함께 증가해야 Flow 유지           │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.1.2. 게임 기본 성격

| 항목                | 설정                           | 심리학적 근거                  |
| :------------------ | :----------------------------- | :----------------------------- |
| **플레이 스타일**   | Factorio 스타일                | 시스템 최적화 = 내재적 보상    |
| **세션 유형**       | 연속 플레이                    | Hyperfocus 유도                |
| **1회차 클리어**    | 목표 50시간 (개인차 40-60시간) | 몰입형 대작 게임 기준          |
| **프레스티지 주기** | 8-15시간 (2회차~)              | 숙련도 향상 + 보너스 누적 효과 |
| **무한 플레이**     | 상한 없음                      | 메가베이스 + 최적화 추구       |
| **난이도 곡선**     | 점진적 상승                    | Flow Zone 유지                 |
| **피드백 지연**     | 0.5-5초                        | 즉각적 만족감                  |

### 4.1.3. 몰입 유지 메커니즘

```javascript
// Flow 유지를 위한 난이도 조절 알고리즘 (개념적)
const FLOW_PARAMETERS = {
  // 현재 플레이어 상태 평가
  player_metrics: {
    idle_time: 0, // 아무 행동 없는 시간 (초)
    action_frequency: 0, // 분당 행동 횟수
    bottleneck_count: 0, // 해결하지 않은 병목 수
    resource_surplus: 0, // 잉여 자원 비율
  },

  // Flow 영역 판정
  flow_zone: {
    // 불안 영역: 도전 과다
    anxiety_indicators: [
      'bottleneck_count > 5',
      'resource_deficit_rate > 50%',
      'failed_missions > 2',
    ],

    // 지루함 영역: 도전 부족
    boredom_indicators: ['idle_time > 30', 'resource_surplus > 300%', 'no_new_unlocks > 10min'],
  },

  // 동적 조정 (힌트 시스템으로 구현)
  adjustments: {
    on_anxiety: 'show_optimization_hint',
    on_boredom: 'suggest_new_challenge',
    on_flow: 'minimal_interference',
  },
}
```

## 4.2. Multi-Layer Loop Architecture

### 4.2.1. 루프 계층 구조

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ╔═══════════════════════════════════════════════════════════════════════╗   │
│ ║ META LOOP (1회차: 목표 50시간 / 2회차+: 8-15시간)                     ║   │
│ ║  └─ 행성 개척 → 기술 트리 완성 → 우주선 완공 → 새 행성 이주           ║   │
│ ║  └─ 프레스티지 보너스 누적, Loadout 최적화                            ║   │
│ ║  └─ 무한 확장: 메가베이스 구축, 분당 생산량 극대화                    ║   │
│ ╚═══════════════════════════════════════════════════════════════════════╝   │
│                                     ▲                                       │
│ ┌───────────────────────────────────────────────────────────────────────┐   │
│ │ SESSION LOOP (2-4시간)                                                │   │
│ │  └─ 마일스톤 달성 → 기술 해금 → 공장 대규모 확장                      │   │
│ │  └─ 생산 체인 복잡화, 새로운 제품 라인 추가                           │   │
│ └───────────────────────────────────────────────────────────────────────┘   │
│                                     ▲                                       │
│   ┌─────────────────────────────────────────────────────────────────────┐   │
│   │ CORE LOOP (10-20분)                                                 │   │
│   │  └─ 목표 수령 → 생산라인 구축 → 병목 발견 → 최적화 → 목표 달성      │   │
│   │  └─ 자원 확보, 물류 설계, 효율 개선                                 │   │
│   └─────────────────────────────────────────────────────────────────────┘   │
│                                     ▲                                       │
│     ┌───────────────────────────────────────────────────────────────────┐   │
│     │ MICRO LOOP (3-10초)                                               │   │
│     │  └─ 건물 배치 → 벨트 연결 → 즉각 피드백                           │   │
│     │  └─ 그리드 스냅, 아이템 흐름 확인, 미세 조정                      │   │
│     └───────────────────────────────────────────────────────────────────┘   │
│                                     ▲                                       │
│       ┌─────────────────────────────────────────────────────────────────┐   │
│       │ TICK LOOP (50ms)                                                │   │
│       │  └─ 시뮬레이션 업데이트, 아이템 이동, 생산 처리                 │   │
│       │  └─ 게임 내부 시간 진행 (플레이어 인지 못함)                    │   │
│       └─────────────────────────────────────────────────────────────────┘   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.2.2. 루프별 상세 사양

| 루프         | 주기                | 주요 활동         | 보상 유형         | 이탈 방지      |
| :----------- | :------------------ | :---------------- | :---------------- | :------------- |
| **Tick**     | 50ms                | 물리 시뮬레이션   | 시각적 만족       | N/A            |
| **Micro**    | 3-10초              | 단일 건물 배치    | 즉각 피드백       | 스냅 가이드    |
| **Core**     | 10-30분             | 생산라인 완성     | 목표 달성 보상    | 진행률 표시    |
| **Session**  | 3-6시간             | 마일스톤 달성     | 해금 + 업적       | 다음 목표 예고 |
| **Meta**     | 목표 50시간 (1회차) | 프레스티지        | 영구 보너스       | 실적 누적 표시 |
| **Infinite** | 무제한              | 메가베이스/최적화 | 자기만족+리더보드 | 통계 중독      |

## 4.3. Micro Loop (3-10초 단위)

### 4.3.1. 배치 시스템

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         PLACEMENT SYSTEM                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [1. 건물 선택]                                                             │
│  └─ 건물 메뉴에서 선택 → 고스트 프리뷰 표시                                │
│     └─ 배치 가능: 녹색 테두리                                              │
│     └─ 배치 불가: 빨간 테두리 + 이유 표시                                  │
│                                                                             │
│  [2. 위치 결정]                                                             │
│  └─ 32px 그리드 스냅                                                       │
│  └─ Shift: 스냅 해제 (16px 미세 조정)                                      │
│  └─ Q/E: 90° 회전                                                          │
│                                                                             │
│  [3. 배치 확정]                                                             │
│  └─ 클릭: 단일 배치                                                        │
│  └─ 드래그: 연속 배치 (컨베이어, 파이프)                                   │
│  └─ Shift+드래그: 직선 드래그 (대각선 방지)                                │
│                                                                             │
│  [4. 즉각 피드백]                                                           │
│  └─ 배치 성공: 메탈 사운드 + 파티클                                        │
│  └─ 자동 연결: 인접 벨트/파이프 자동 연결 표시                             │
│  └─ 비용 차감: HUD 자원 숫자 애니메이션                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.3.2. 병목 시각화

| 상태            | 시각적 표현             | 의미           |
| :-------------- | :---------------------- | :------------- |
| **정상 흐름**   | 아이템이 부드럽게 이동  | 최적 상태      |
| **경미한 적체** | 아이템 간격 좁아짐      | 주의 필요      |
| **심각한 적체** | 아이템 정지 + 빨간 표시 | 즉시 조치      |
| **입력 부족**   | 시설 "대기" 표시        | 공급 라인 확인 |
| **출력 막힘**   | 시설 "정지" 표시        | 출력 라인 확인 |

### 4.3.3. 자원 이동 시뮬레이션

```javascript
// 자원 이동 시뮬레이션 파라미터
const LOGISTICS_PARAMS = {
  // 컨베이어 벨트 속도 (아이템/초)
  conveyor_speeds: {
    basic: 2, // 기본 벨트: 2 아이템/초
    fast: 4, // 고속 벨트: 4 아이템/초
    express: 8, // 극속 벨트: 8 아이템/초
  },

  // 벨트당 최대 아이템 수
  belt_capacity: {
    per_tile: 4, // 타일당 4개 아이템 적재 가능
  },

  // 투입기 속도 (아이템/초)
  inserter_speeds: {
    basic: 0.83, // 기본: 1.2초/개
    fast: 2, // 고속: 0.5초/개
    stack: 6, // 스택: 12개/2초
  },

  // 시각적 이동
  visual: {
    smooth_movement: true,
    item_spacing: 8, // px
    animation_fps: 60,
  },
}
```
