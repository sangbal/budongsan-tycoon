## 3.7. 애니메이션 시스템 (Animation)

### 3.7.1. 타이밍 함수

```javascript
// 이징 함수 정의
const EASING = {
  // 기본 전환 (버튼, 패널)
  standard: 'cubic-bezier(0.4, 0.0, 0.2, 1)', // Material Design standard

  // 들어오는 애니메이션 (팝업, 토스트)
  decelerate: 'cubic-bezier(0.0, 0.0, 0.2, 1)',

  // 나가는 애니메이션 (닫기, 페이드아웃)
  accelerate: 'cubic-bezier(0.4, 0.0, 1, 1)',

  // 물리 기반 (드래그, 스프링)
  spring: 'cubic-bezier(0.175, 0.885, 0.32, 1.275)',

  // 숫자 카운터 (자원 변화)
  linear: 'linear',
}

// 애니메이션 지속 시간 (ms)
const DURATION = {
  instant: 100, // 즉각 피드백 (버튼 눌림)
  fast: 150, // 빠른 전환 (호버 상태)
  normal: 250, // 기본 전환 (패널 열기)
  slow: 350, // 강조 전환 (모달)
  emphasis: 500, // 중요 이벤트 (업적 달성)
}
```

### 3.7.2. 애니메이션 카탈로그

| 애니메이션        | 트리거       | 지속시간      | 이징                  |
| :---------------- | :----------- | :------------ | :-------------------- |
| **버튼 눌림**     | click        | 100ms         | standard              |
| **호버 확대**     | hover        | 150ms         | standard              |
| **패널 슬라이드** | open/close   | 250ms         | decelerate/accelerate |
| **토스트 등장**   | notification | 300ms         | spring                |
| **숫자 카운터**   | value change | 500ms         | linear                |
| **업적 팝업**     | achievement  | 800ms         | spring                |
| **화면 전환**     | page change  | 350ms         | standard              |
| **로딩 스피너**   | loading      | 1000ms (loop) | linear                |

### 3.7.3. 게임 오브젝트 애니메이션

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    GAME OBJECT ANIMATIONS                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [컨베이어 벨트]                                                            │
│  ├─ 아이템 이동: 0.5초/타일 (속도 업그레이드로 변동)                       │
│  ├─ 방향 화살표: 0.8초 루프 펄스                                           │
│  └─ 막힘 상태: 빨간 점멸 1초 주기                                          │
│                                                                             │
│  [생산 시설]                                                                │
│  ├─ 가동 중: 내부 기어/파이프 애니메이션 2초 루프                          │
│  ├─ 생산 완료: 아이템 팝 + 파티클                                          │
│  ├─ 정지: 애니메이션 정지 + 회색 오버레이                                  │
│  └─ 과부하: 빨간 외곽선 펄스 0.5초                                         │
│                                                                             │
│  [자원 노드]                                                                │
│  ├─ 채굴 중: 파티클 분출 (1초당 5개)                                       │
│  ├─ 고갈 임박: 노드 크기 축소 애니메이션                                   │
│  └─ 완전 고갈: 페이드아웃 + 먼지 파티클                                    │
│                                                                             │
│  [드론/운송]                                                                │
│  ├─ 비행: 호버링 상하 움직임 ±2px                                          │
│  ├─ 이동: 베지어 곡선 경로                                                 │
│  ├─ 픽업/드롭: 스케일 애니메이션                                           │
│  └─ 충돌 회피: 부드러운 경로 수정                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.7.4. 성능 최적화 규칙

| 규칙              | 설명                            | 구현                   |
| :---------------- | :------------------------------ | :--------------------- |
| **GPU 가속**      | transform, opacity만 애니메이션 | `will-change` 속성     |
| **레이어 분리**   | 자주 변하는 요소 별도 레이어    | 컴포지팅 레이어        |
| **프레임 예산**   | 16.67ms (60fps) 이내            | requestAnimationFrame  |
| **배치 업데이트** | DOM 조작 최소화                 | 가상 DOM / 배치 처리   |
| **가시성 컬링**   | 화면 밖 요소 애니메이션 중지    | Intersection Observer  |
| **저전력 모드**   | 배터리 절약 시 애니메이션 감소  | prefers-reduced-motion |

## 3.8. 메뉴 시스템 (Menu Structure)

### 3.8.1. 메인 메뉴 계층

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                              메인 메뉴 (≡)                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐           │
│  │ 📊      │  │ 🔬      │  │ 📋      │  │ 🏆      │  │ ⚙️      │           │
│  │ 통계    │  │ 연구소  │  │ 미션    │  │ 업적    │  │ 설정    │           │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘  └─────────┘           │
│                                                                             │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐                        │
│  │ 🗺️      │  │ 💾      │  │ 📖      │  │ ❓      │                        │
│  │ 맵 보기 │  │ 저장    │  │ 도감    │  │ 도움말  │                        │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.8.2. 메뉴 상세 기능

| 메뉴           | 하위 기능                                   | 단축키    |
| :------------- | :------------------------------------------ | :-------- |
| **📊 통계**    | 생산량 그래프, 소비량, 병목 분석, 효율 점수 | S         |
| **🔬 연구소**  | 테크 트리, 연구 큐, 자동 연구 설정          | T         |
| **📋 미션**    | 활성 미션, 완료 미션, 보상 수령             | M         |
| **🏆 업적**    | 달성/미달성 업적, 진행률, 보상              | A         |
| **⚙️ 설정**    | 그래픽, 사운드, 언어, 접근성, 계정          | , (comma) |
| **🗺️ 맵 보기** | 전체 맵, 자원 노드, 탐사 영역               | N         |
| **💾 저장**    | 수동 저장, 불러오기, 클라우드, 내보내기     | Ctrl+S    |
| **📖 도감**    | 건물, 자원, 김치 종류, 발견 기록            | B         |
| **❓ 도움말**  | 튜토리얼, 팁, FAQ, 버전 정보                | F1        |
