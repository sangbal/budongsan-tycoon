## 3.9. Master Plan Mode (전략 오버레이)

### 3.9.1. 개요

**토글:** Tab (PC) / 두 손가락 더블탭 (모바일)

게임 뷰 위에 반투명 오버레이로 표시되는 전략적 분석 모드.

┌─────────────────────────────────────────────────────────────────────────────┐

### 3.9.3. 시각화 요소

| 요소              | 시각화                | 의미                     |
| :---------------- | :-------------------- | :----------------------- |
| **🟢 녹색 노드**  | 시설 + 녹색 원        | 정상 가동 (80-100% 효율) |
| **🟡 노란 노드**  | 시설 + 노란 원        | 유휴/저효율 (50-79%)     |
| **🔴 빨간 노드**  | 시설 + 빨간 원 + 펄스 | 병목/과부하 (>100%)      |
| **→ 녹색 화살표** | 물류 흐름선           | 정상 흐름                |
| **→ 빨간 화살표** | 물류 흐름선 (점선)    | 막힘/대기                |
| **히트맵**        | 영역 색상 그라데이션  | 전력/열 분포             |

### 3.9.4. 분석 메트릭

```javascript
// Master Plan Mode에서 계산되는 메트릭
const MASTER_PLAN_METRICS = {
  // 생산 효율
  production: {
    current_rate: 12, // 현재 분당 생산량
    target_rate: 20, // 목표 분당 생산량
    efficiency: 60, // 효율 % (current/target)
    bottleneck: 'fermentor', // 병목 시설 ID
    bottleneck_reason: 'capacity_exceeded',
  },

  // 물류 효율
  logistics: {
    throughput: 85, // 물류 처리율 %
    idle_conveyors: 3, // 유휴 컨베이어 수
    blocked_paths: 1, // 막힌 경로 수
    drone_utilization: 72, // 드론 가동률 %
  },

  // 전력 현황
  power: {
    consumption: 450, // 현재 소비 kW
    capacity: 500, // 총 발전 용량 kW
    usage_percent: 90, // 사용률 %
    reserve: 50, // 여유 전력 kW
    warning: true, // 경고 상태
  },

  // 권장 조치
  recommendations: [
    { action: 'add_building', type: 'fermentor', count: 2, impact: '+8/분', cost: 5000 },
    { action: 'optimize_path', target: 'drone_route_3', impact: '+5%', cost: 0 },
  ],
}
```

## 3.11. 화성 환경 UI 변화

### 3.11.1. 시간대별 UI 변화

| 화성 시간              | 배경 색조     | UI 요소             |
| :--------------------- | :------------ | :------------------ |
| **새벽 (04:00-06:00)** | 암청색 → 주황 | 태양광 예열 표시    |
| **오전 (06:00-12:00)** | 밝은 주황     | 최적 태양광 표시    |
| **오후 (12:00-18:00)** | 붉은 주황     | 정상 가동           |
| **저녁 (18:00-20:00)** | 주황 → 암청색 | 야간 모드 전환 경고 |
| **밤 (20:00-04:00)**   | 암청색        | 태양광 비활성 표시  |
