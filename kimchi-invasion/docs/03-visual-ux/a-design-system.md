## 3.1. 디자인 철학: Mission Control Aesthetics

### 3.1.1. 핵심 원칙

**"모든 픽셀에는 목적이 있다"** - NASA Johnson Space Center의 Mission Control Room에서 영감

| 원칙            | 설명                    | 적용                    |
| :-------------- | :---------------------- | :---------------------- |
| **정보 밀도**   | 최소 공간에 최대 정보   | HUD는 화면의 10% 이하   |
| **상태 가시성** | 시스템 상태를 즉시 파악 | 색상 코드 + 숫자 병기   |
| **예측 가능성** | 동일 입력 = 동일 결과   | 일관된 인터랙션 패턴    |
| **오류 방지**   | 위험한 행동 전 확인     | 삭제/리셋 시 2단계 확인 |
| **맥락 인식**   | 현재 상황에 맞는 UI     | 위기 시 자동 경고 표시  |

### 3.1.2. 레퍼런스 분석

실제 우주 미션 컨트롤 UI에서 추출한 디자인 요소:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        REFERENCE ANALYSIS                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [NASA Mission Control]        [SpaceX Dragon UI]      [ISS ECLSS Panel]   │
│  ├─ 다크 배경 + 고대비        ├─ 미니멀 타이포        ├─ 상태 트리 구조    │
│  ├─ 레이어 기반 정보 계층     ├─ 터치 최적화 버튼     ├─ 경고 색상 체계    │
│  ├─ 실시간 텔레메트리 그래프  ├─ 라운드 코너          ├─ 시스템 연결 표시  │
│  └─ 그리드 정렬               └─ 애니메이션 피드백    └─ 이중화 표시      │
│                                                                             │
│  [Tesla Dashboard]             [Factorio UI]           [Satisfactory]      │
│  ├─ 정보 계층 단순화          ├─ 아이템 그리드        ├─ 3D→2D 전환       │
│  ├─ 중앙 집중 디스플레이      ├─ 툴팁 상세 정보       ├─ 미니맵 통합      │
│  ├─ 실시간 상태 업데이트      ├─ 생산 체인 시각화     ├─ 알림 큐 시스템   │
│  └─ 다크 모드 기본            └─ 블루프린트 모드      └─ 건설 미리보기   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1.3. 화성 환경 반영 원칙

게임 UI는 화성의 극한 환경을 **시각적으로 전달**해야 함:

| 환경 요소      | UI 반영 방식                            |
| :------------- | :-------------------------------------- |
| **먼지 폭풍**  | 화면 가장자리 붉은 비네팅 + 경고 아이콘 |
| **낮/밤 주기** | 상단 바 시간 표시 + 배경 색조 변화      |
| **방사선**     | 위험 구역 점선 표시 + 방호복 상태 UI    |
| **저압 환경**  | 시설 내부/외부 구분선 명확화            |
| **극저온**     | 난방 범위 오버레이 (히트맵)             |

### 3.2.2. 상태 색상 (Status Colors)

| 상태       | 색상      | HEX       | 용도                        | WCAG 대비 |
| :--------- | :-------- | :-------- | :-------------------------- | :-------- |
| **정상**   | 🟢 Green  | `#10B981` | 정상 가동, 충분한 자원      | 4.5:1 ✓   |
| **주의**   | 🟡 Amber  | `#F59E0B` | 자원 부족, 효율 저하        | 3.2:1 △   |
| **경고**   | 🟠 Orange | `#F97316` | 시설 과부하, 재고 소진 임박 | 3.1:1 △   |
| **위험**   | 🔴 Red    | `#EF4444` | 시스템 정지, 즉시 조치 필요 | 4.8:1 ✓   |
| **비활성** | ⚫ Gray   | `#6B7280` | 전원 꺼짐, 미해금           | 5.3:1 ✓   |
| **선택됨** | 🔵 Blue   | `#3B82F6` | 현재 선택, 포커스           | 4.5:1 ✓   |
| **특수**   | 🟣 Purple | `#8B5CF6` | 프레스티지, 희귀            | 4.2:1 ✓   |

```javascript

  // 완제품 (김치)
  kimchi_basic: '#E63946', // 김치 레드
  kimchi_premium: '#C41E3A', // 진한 레드
```

## 3.3. 타이포그래피 시스템 (Typography)

### 3.3.1. 폰트 계층

| 용도               | 폰트           | 크기 | 굵기 | 행간 |
| :----------------- | :------------- | :--- | :--- | :--- |
| **대제목 (H1)**    | Space Grotesk  | 32px | 700  | 1.2  |
| **섹션 제목 (H2)** | Space Grotesk  | 24px | 600  | 1.3  |
| **소제목 (H3)**    | Space Grotesk  | 18px | 600  | 1.4  |
| **본문**           | Inter          | 14px | 400  | 1.5  |
| **캡션**           | Inter          | 12px | 400  | 1.4  |
| **숫자 (모노)**    | JetBrains Mono | 14px | 500  | 1.2  |
| **HUD 숫자**       | JetBrains Mono | 16px | 600  | 1.0  |
| **버튼 텍스트**    | Inter          | 14px | 500  | 1.0  |

### 3.3.2. 숫자 표기 규칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       NUMBER FORMATTING RULES                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [자원량]                          [비율/퍼센트]                            │
│  ├─ < 1,000: 정수 표시             ├─ 정수%: "85%"                         │
│  │   예: "847"                     ├─ 소수점: "12.5%"                      │
│  ├─ < 1,000,000: K 단위            └─ 변화량: "+3.2%" / "-1.5%"            │
│  │   예: "12.3K"                                                           │
│  ├─ < 1,000,000,000: M 단위        [시간 표시]                              │
│  │   예: "5.67M"                   ├─ 화성 시간: "Sol 47, 14:32"           │
│  ├─ < 1조: B 단위                  ├─ 카운트다운: "2:34" (분:초)           │
│  │   예: "2.34B"                   ├─ 생산 속도: "5/분"                    │
│  └─ ≥ 1조: T 단위                  └─ 남은 시간: "~3분" (추정)             │
│      예: "1.00T"                                                           │
│                                                                             │
│  [특수 규칙]                                                                │
│  ├─ 모든 숫자는 모노스페이스 폰트                                          │
│  ├─ 증가/감소 시 색상 표시 (녹색/적색)                                     │
│  ├─ 큰 숫자 변화 시 "pop" 애니메이션                                       │
│  └─ 툴팁에서 정확한 값 표시                                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3.4. 아이콘 시스템 (Iconography)

### 3.4.1. 아이콘 그리드

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          ICON GRID SYSTEM                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  기본 그리드: 24x24px                                                       │
│  패딩 영역: 2px (실제 아이콘: 20x20px)                                      │
│  선 굵기: 1.5px (기본), 2px (강조)                                          │
│  모서리 반경: 2px                                                           │
│                                                                             │
│  ┌────────────────┐                                                         │
│  │  ┌──────────┐  │  ← 24px 컨테이너                                       │
│  │  │          │  │                                                         │
│  │  │  ICON    │  │  ← 20px 아이콘 영역                                    │
│  │  │          │  │                                                         │
│  │  └──────────┘  │                                                         │
│  └────────────────┘                                                         │
│     ↑ 2px 패딩                                                              │
│                                                                             │
│  크기 변형:                                                                 │
│  ├─ 16px: 인라인 텍스트, 탭 아이콘                                         │
│  ├─ 24px: 기본 UI 아이콘                                                   │
│  ├─ 32px: 건물 메뉴, 연구 트리                                             │
│  └─ 48px: 빈 상태 일러스트, 튜토리얼                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.4.2. 핵심 아이콘 세트

| 카테고리 | 아이콘         | 용도                                   |
| :------- | :------------- | :------------------------------------- |
| **자원** | 💰 💎 ⚡ 🔬 🧬 | 크레딧, 희귀자원, 전력, 연구점, 유전자 |
| **건물** | 🏗️ ⛏️ 🌱 🏭 🔬 | 건설, 채굴, 농업, 제조, 연구           |
| **물류** | ➡️ ↩️ 📦 🚀 🛸 | 컨베이어, 회전, 창고, 발사대, 드론     |
| **상태** | ✅ ⚠️ ❌ ⏸️ ▶️ | 정상, 경고, 오류, 정지, 가동           |
| **UI**   | ⚙️ ❓ 📊 🗺️ 💾 | 설정, 도움말, 통계, 맵, 저장           |
