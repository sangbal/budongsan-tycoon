## 3.15. 접근성 종합 가이드 (Accessibility)

> 📎 **목표:** WCAG 2.1 AA 수준 준수

### 3.15.1. 시각 접근성

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    👁️ 시각 접근성 체크리스트                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  ◆ 색상 대비 (Color Contrast)                                               │
│  ─────────────────────────────────────────────────────────────────────────  │
│  • 텍스트/배경: 최소 4.5:1 (일반), 3:1 (대형 텍스트)                        │
│  • 그래픽 요소: 최소 3:1 (버튼, 아이콘 등)                                  │
│  • 색맹 모드: Protanopia, Deuteranopia, Tritanopia 지원                     │
│  • 색상만으로 정보 전달 금지 → 아이콘/패턴 병행 사용                        │
│                                                                             │
│  ◆ 텍스트 가독성                                                            │
│  ─────────────────────────────────────────────────────────────────────────  │
│  • 최소 폰트 크기: 14px (모바일 16px)                                       │
│  • 줄 간격: 최소 1.5배                                                      │
│  • 텍스트 크기 조절: 200%까지 확대 가능                                     │
│  • 고대비 모드: 배경/전경 대비 강화                                         │
│                                                                             │
│  ◆ 애니메이션 접근성                                                        │
│  ─────────────────────────────────────────────────────────────────────────  │
│  • prefers-reduced-motion 미디어 쿼리 존중                                  │
│  • 깜빡임: 초당 3회 미만                                                    │
│  • 자동 애니메이션: 일시정지 가능                                           │
│  • 모션 감소 모드: 필수 전환만 유지                                         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.15.2. 청각 접근성

| 요소            | 대응 방안                 | 구현 상태 |
| :-------------- | :------------------------ | :-------- |
| **알림 사운드** | 시각적 표시 + 진동 병행   | 필수      |
| **경고음**      | 화면 깜빡임 / 아이콘 표시 | 필수      |
| **배경 음악**   | 음소거 기본값 / 별도 볼륨 | 필수      |
| **효과음**      | 시각 피드백 항상 제공     | 필수      |

### 3.15.3. 운동 접근성

```javascript
// 접근성 입력 설정 (추가)
const ACCESSIBILITY_INPUT = {
  // 클릭 영역
  minTouchTarget: 44, // 44x44px 최소 터치 영역 (WCAG)
  minClickTarget: 24, // 24x24px 최소 클릭 영역

  // 시간 제한
  extendedTimeouts: true, // 시간 제한 연장 옵션
  pauseOnInactivity: true, // 비활성 시 일시정지

  // 단축키
  customKeyBindings: true, // 사용자 정의 키 바인딩
  singleHandMode: true, // 한 손 모드 (왼손/오른손)

  // 마우스 설정
  mouseClickHold: {
    enabled: true,
    threshold: 500, // ms - 롱클릭 인식 시간
  },
}
```

### 3.15.4. 인지 접근성

| 원칙                  | 구현                      | 설명                   |
| :-------------------- | :------------------------ | :--------------------- |
| **명확한 레이블**     | 모든 버튼/아이콘에 텍스트 | 아이콘만 사용 금지     |
| **일관된 네비게이션** | 동일 위치, 동일 순서      | 학습 곡선 최소화       |
| **오류 방지**         | 확인 다이얼로그           | 되돌릴 수 없는 작업 전 |
| **진행 상황 표시**    | 로딩/처리 중 명확히       | 시각적 피드백 필수     |
| **단순한 언어**       | 전문 용어 최소화          | 툴팁으로 설명 제공     |

### 3.15.5. 스크린 리더 지원

```html
<!-- ARIA 레이블 예시 -->
<button aria-label="배추김치 생산 시작" aria-describedby="kimchi-tooltip" role="button">
  <img src="kimchi-icon.png" alt="" aria-hidden="true" />
</button>

<!-- 라이브 영역 (실시간 업데이트) -->
<div aria-live="polite" aria-atomic="true" class="production-status">배추김치 생산 완료: 150개</div>

<!-- 건너뛰기 링크 -->
<a href="#main-game" class="skip-link"> 메인 게임으로 건너뛰기 </a>
```

### 3.15.6. 접근성 설정 메뉴

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    ⚙️ 접근성 설정                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【 시각 】                                                                  │
│  [ ] 색맹 모드 ─────────── [해제 ▼] (적록/청황/전색맹)                      │
│  [ ] 고대비 모드 ────────── [OFF]                                           │
│  [ ] 텍스트 크기 ────────── [100% ▼] (75% ~ 200%)                           │
│  [ ] 모션 감소 ─────────── [OFF]                                            │
│  [ ] 깜빡임 효과 ────────── [ON]                                            │
│                                                                             │
│  【 청각 】                                                                  │
│  [ ] 시각적 알림 ────────── [ON] (사운드 대신 시각 피드백)                  │
│  [ ] 화면 깜빡임 경고 ───── [ON] (경고음 대신)                              │
│  [ ] 자막 ───────────────── [ON] (대사/나레이션)                            │
│                                                                             │
│  【 조작 】                                                                  │
│  [ ] 한 손 모드 ─────────── [해제 ▼] (왼손/오른손)                          │
│  [ ] 롱클릭 시간 ────────── [500ms ▼]                                       │
│  [ ] 키보드 전용 모드 ───── [OFF]                                           │
│  [ ] 자동 일시정지 ──────── [ON] (비활성 시)                                │
│                                                                             │
│  【 인지 】                                                                  │
│  [ ] 튜토리얼 힌트 ──────── [ON]                                            │
│  [ ] 확인 다이얼로그 ────── [ON] (중요 작업 전)                             │
│  [ ] 간소화 UI ─────────── [OFF] (정보 최소화)                              │
│                                                                             │
│                        [ 기본값으로 복원 ]                                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
