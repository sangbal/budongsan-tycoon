## 3.6. 조작 방식 (Input System)

### 3.6.1. PC 조작 (키보드 + 마우스)

| 입력               | 동작                    | 맥락                       |
| :----------------- | :---------------------- | :------------------------- |
| **클릭**           | 선택 / 배치             | 건물 선택, 그리드 배치     |
| **우클릭**         | 취소 / 삭제 모드        | 배치 취소, 삭제 도구       |
| **드래그**         | 카메라 이동             | 맵 탐색                    |
| **Shift + 드래그** | 다중 선택               | 범위 선택                  |
| **스크롤**         | 확대/축소 (0.5x ~ 3.0x) | 줌 레벨 조정               |
| **Q / E**          | 회전 (90° 단위)         | 건물/벨트 방향             |
| **R**              | 복사 모드               | 선택 건물 복제             |
| **Delete**         | 선택 항목 삭제          | 확인 다이얼로그 표시       |
| **ESC**            | 취소 / 메뉴             | 계층적 취소                |
| **1-5**            | 툴바 단축키             | 건물/벨트/물류/에너지/연구 |
| **Space**          | 일시정지 토글           | 게임 일시 정지             |
| **Tab**            | Master Plan 모드        | 오버레이 대시보드          |
| **Ctrl + S**       | 수동 저장               | 즉시 저장                  |
| **Ctrl + Z**       | 실행 취소               | 최근 10개 동작             |
| **Ctrl + Y**       | 다시 실행               | 취소된 동작 복원           |

### 3.6.2. 모바일 조작 (터치 제스처)

| 제스처                 | 동작               | 피드백             |
| :--------------------- | :----------------- | :----------------- |
| **탭**                 | 선택 / 배치        | 햅틱 피드백 (짧게) |
| **길게 누르기 (0.5s)** | 정보 / 삭제 모드   | 햅틱 피드백 (길게) |
| **드래그**             | 카메라 이동        | 관성 스크롤        |
| **핀치**               | 확대/축소          | 중심점 기준 줌     |
| **두 손가락 회전**     | 건물 회전          | 90° 스냅           |
| **스와이프 (하단 바)** | 툴바 카테고리 전환 | 페이지 인디케이터  |
| **위로 스와이프**      | 건물 메뉴 열기     | 스프링 애니메이션  |
| **아래로 스와이프**    | 메뉴 닫기          | 스프링 애니메이션  |
| **두 손가락 더블탭**   | Master Plan 토글   | 오버레이 전환      |
| **세 손가락 탭**       | 스크린샷           | 저장 토스트 표시   |

### 3.6.3. 접근성 입력 지원

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      ACCESSIBILITY INPUT SUPPORT                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [키보드 내비게이션]                                                        │
│  ├─ Tab: UI 요소 간 이동                                                   │
│  ├─ Arrow Keys: 그리드 내 커서 이동                                        │
│  ├─ Enter: 선택/확인                                                       │
│  ├─ Escape: 취소/뒤로                                                      │
│  └─ ?: 단축키 도움말 표시                                                  │
│                                                                             │
│  [스크린 리더 지원]                                                         │
│  ├─ ARIA 레이블: 모든 인터랙티브 요소                                      │
│  ├─ 라이브 리전: 자원 변화, 알림                                           │
│  ├─ 랜드마크: 주요 UI 영역                                                 │
│  └─ 읽기 순서: 논리적 탭 순서                                              │
│                                                                             │
│  [모터 장애 지원]                                                           │
│  ├─ 큰 터치 타겟 모드: 56x56px                                             │
│  ├─ 드웰 클릭: 호버 1초 후 자동 클릭                                       │
│  ├─ 스티키 키: 조합키 순차 입력                                            │
│  └─ 커스텀 키 매핑: 모든 단축키 재설정 가능                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
