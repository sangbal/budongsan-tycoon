## 10.1. 오디오 디자인 철학: MARS 프레임워크

> **"화성의 적막함 속에서 김치 공장이 살아 숨쉬는 소리"**

### MARS 원칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    🔊 MARS 오디오 디자인 프레임워크                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  M - Meaningful (의미 있는)                                                 │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 모든 사운드는 게임플레이 정보를 전달해야 한다                            │
│  • 장식적 사운드 최소화, 기능적 사운드 극대화                               │
│  • 시각 정보 없이도 게임 상태 파악 가능 (접근성)                            │
│  • 예: 기계 소리만으로 가동률 추정 가능                                     │
│                                                                             │
│  A - Adaptive (적응형)                                                      │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 게임 상태에 따라 동적으로 변화                                           │
│  • 레이어 기반 믹싱으로 자연스러운 전환                                     │
│  • 플레이어 활동에 반응하는 살아있는 사운드스케이프                         │
│  • 절대 루프가 느껴지지 않도록 설계                                         │
│                                                                             │
│  R - Realistic (사실적)                                                     │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 화성 환경의 물리적 특성 반영                                             │
│  • 희박한 대기 → 실외 소리 감쇠                                             │
│  • 밀폐 공간 → 실내 반향과 기계음                                           │
│  • SF 앰비언트로 우주적 스케일 표현                                         │
│                                                                             │
│  S - Subtle (절제된)                                                        │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 과도한 사운드는 피로감 유발                                              │
│  • 중요한 순간에만 강조 (희소성의 법칙)                                     │
│  • 배경음은 은은하게, 알림음은 명확하게                                     │
│  • 장시간 플레이에도 불편함 없는 믹싱                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 레퍼런스 사운드스케이프

| 참조 작품            | 가져올 요소            | 적용 방식         |
| :------------------- | :--------------------- | :---------------- |
| **Interstellar OST** | 오르간 드론, 시간 왜곡 | 프레스티지 시퀀스 |
| **The Martian OST**  | 고독감, 낙관적 긴장    | 기본 앰비언트     |
| **Factorio**         | 기계 리듬, 생산 만족감 | 공장 환경음       |
| **No Man's Sky**     | 절차적 생성 앰비언트   | 행성별 음악       |
| **Alien Isolation**  | 밀폐 공간 공포         | 위기 상황 사운드  |

### 감정 매핑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    🎭 게임 상태 → 감정 → 사운드 매핑                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  [게임 상태]              [목표 감정]           [사운드 특성]               │
│                                                                             │
│  초반 수동 단계    →     호기심, 고독     →    미니멀, 공간감               │
│  자동화 시작      →     성취감, 희망     →    리드미컬, 상승               │
│  공장 확장        →     몰입, 조화       →    폴리리듬, 풍성               │
│  위기 상황        →     긴장, 집중       →    불협화음, 긴박               │
│  목표 달성        →     쾌감, 자부심     →    팡파르, 해소                 │
│  프레스티지       →     경외, 기대       →    에픽, 우주적                 │
│  메가베이스       →     자기효능감       →    웅장, 복잡                   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
