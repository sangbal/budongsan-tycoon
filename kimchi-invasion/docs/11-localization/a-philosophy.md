## 11.1. 로컬라이제이션 철학: GLOBAL 프레임워크

> **"김치의 맛은 세계 공통, 표현은 각 문화에 맞게"**

### GLOBAL 원칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    🌐 GLOBAL 로컬라이제이션 프레임워크                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  G - Genuine (진정성)                                                       │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 한국 문화의 본질을 왜곡 없이 전달                                        │
│  • 김치, 김장, 할머니의 유산 - 번역이 아닌 문화 전달                        │
│  • "Kimchi"는 전 세계 공용어 (번역하지 않음)                                │
│  • 문화적 맥락을 설명하되, 이국적으로 만들지 않음                           │
│                                                                             │
│  L - Local (현지화)                                                         │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 각 시장의 문화적 기대에 맞춤                                             │
│  • 일본: 발효 과학 강조 (식품 문화 존중)                                    │
│  • 미국: SF/기술 혁신 강조                                                  │
│  • 유럽: 지속가능성, 생태계 강조                                            │
│  • 날짜, 숫자, 단위 등 형식 현지화                                          │
│                                                                             │
│  O - Optimized (최적화)                                                     │
│  ────────────────────────────────────────────────────────────────────────   │
│  • UI 공간에 맞는 텍스트 길이                                               │
│  • 폰트 렌더링 최적화 (CJK 특수 처리)                                       │
│  • 번역 파일 지연 로딩 (성능 우선)                                          │
│  • 런타임 언어 전환 지원                                                    │
│                                                                             │
│  B - Brand-consistent (브랜드 일관성)                                       │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 주인공의 캐릭터성 유지 (낙천적, 유머러스)                                │
│  • 게임 톤 유지 (희망적, 도전적)                                            │
│  • 용어집으로 일관된 번역 보장                                              │
│  • 감정적 뉘앙스 보존                                                       │
│                                                                             │
│  A - Accessible (접근성)                                                    │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 모든 언어에서 WCAG 2.1 AA 준수                                           │
│  • 스크린 리더 호환 텍스트                                                  │
│  • 색상에만 의존하지 않는 정보 전달                                         │
│  • 읽기 쉬운 문장 구조                                                      │
│                                                                             │
│  L - Living (살아있는)                                                      │
│  ────────────────────────────────────────────────────────────────────────   │
│  • 지속적인 번역 품질 개선                                                  │
│  • 커뮤니티 피드백 반영                                                     │
│  • 새 콘텐츠 신속 번역 파이프라인                                           │
│  • 버전별 번역 동기화                                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 11.2. 지원 언어 및 우선순위

### 11.2.1. 언어 티어 시스템

> **⚠️ MVP 범위 결정 (2026-01-19)**
>
> - **MVP (M1~M2):** Tier 1만 지원 (한국어, 영어)
> - **Tier 2/3/4:** Post-Launch (Early Access 이후 순차 추가)


### 11.2.2. 언어별 상세 정보

| 언어           | 코드    | 방향 | 복수형 | 폰트         | 난이도 | 시장 규모 |
| :------------- | :------ | :--- | :----- | :----------- | :----- | :-------- |
| 한국어         | `ko`    | LTR  | 없음   | Pretendard   | 기준   | 5,200만   |
| 영어           | `en`    | LTR  | 2개    | Inter        | 낮음   | 15억+     |

| 중국어(번체)   | `zh-TW` | LTR  | 없음   | Noto Sans TC | 중간   | 2,400만   |
| 스페인어       | `es`    | LTR  | 2개    | Inter        | 낮음   | 5억+      |

### 11.2.3. 언어 감지 및 폴백

```javascript
// 언어 감지 우선순위
const LANGUAGE_DETECTION_ORDER = {
  // 1. URL 파라미터 (최우선)
  url_param: '?lang=ko',

  // 2. 로컬 스토리지 (사용자 선택 기억)
  local_storage: 'kimchi_invasion_lang',

  // 3. 브라우저 언어
  browser_lang: navigator.language || navigator.userLanguage,

  // 4. 기본값
  fallback: 'en',
}

// 폴백 체인
const FALLBACK_CHAINS = {
  ko: ['ko'], // 한국어는 폴백 없음 (원본)
  en: ['en'], // 영어도 폴백 없음 (기본)
  ja: ['ja', 'en'], // 일본어 → 영어
  'zh-CN': ['zh-CN', 'zh-TW', 'en'], // 간체 → 번체 → 영어
  'zh-TW': ['zh-TW', 'zh-CN', 'en'], // 번체 → 간체 → 영어
  es: ['es', 'en'], // 스페인어 → 영어
  'es-419': ['es-419', 'es', 'en'], // 라틴 아메리카 → 스페인 → 영어
  'pt-BR': ['pt-BR', 'pt', 'es', 'en'], // 브라질 → 포르투갈 → 스페인 → 영어
  de: ['de', 'en'],
  fr: ['fr', 'en'],
  ru: ['ru', 'en'],
}
```
