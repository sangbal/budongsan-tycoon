## 섹션별 바로가기

### [2.0. 시스템 개요](./02a-system-overview.md)

- 자원 계층 구조 (Lvl 0-5)
- 핵심 시스템 연결도
- 화성 환경이 생산에 미치는 영향 (중력, 대기압, 기온, 먼지폭풍, 방사선)

### [2.1. 자원 경제](./02b-resources.md)

- **원자재 (Lvl 0)**: 레골리스, 철광석, 지하 얼음, 씨앗, 모래
- **1차 가공품 (Lvl 1)**: 철판, 물, 소금, 배추 등 작물
- **2차 가공품 (Lvl 2)**: 양념류, 절임류, 공업 부품
- **완제품 (Lvl 3)**: 김치 6종 (배추김치, 깍두기, 파김치, 오이소박이 등)
- **연구 자원 (Lvl 4)**: 유산균 데이터, 배양액
- **희귀 자원 (Lvl 5)**: 지구 달러, 핵연료

### [2.2. 건물/시설](./02c-buildings.md)

- **채굴 시설**: 표면 채굴기, 드릴, 씨앗 자판기, 모래 채취기
- **가공 시설**: 용광로, 해동기, 양념 제조기, 절임소
- **생산 시설**: 온실, 수경 재배실, 발효실
- **물류 시설**: 컨베이어, 저장소, 분류기
- **에너지 시설**: 태양광, 풍력, 원자력, 배터리
- **연구/특수 시설**: 연구소, 관측소, 지휘 센터

### [2.3-2.5. 인프라 시스템](./02d-infrastructure.md)

- **물류 시스템**: 메인 버스, 셀 기반 설계, 화성 환경 과제
- **전력망**: HUD, 우선순위, 먼지폭풍 대응, 일조 주기
- **건설 비용**: 등급별 비용 매트릭스, 업그레이드, 철거 환불

## 핵심 생산 체인 요약

```
【 배추김치 생산 체인 】

[철광석] → [용광로] → [철판] → (건물 건설)
                          ↓
[지하 얼음] → [해동기] → [물] ─┬→ [소금] ←[염전]
                              │
                              ↓
[씨앗] ─────→ [온실] → [배추] → [절임소] → [절임 배추]
                          ↓
[고춧가루+마늘+젓갈] → [양념] → [발효실] → [배추김치]
```
