## 2.0.1. 화성 환경이 생산에 미치는 영향

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              🔴 MARS ENVIRONMENTAL FACTORS - 생산 시스템 영향               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【 중력 (0.38G) 】                                                          │
│  ───────────────────────────────────────────────────────────────────────    │
│  • 건설 작업: 무거운 장비 이동 용이 → 건설 속도 +20%                        │
│  • 컨베이어: 수직 이동 에너지 감소 → 물류 효율 +15%                         │
│  • 액체 취급: 표면 장력 증가 → 절임/발효 공정 조정 필요                     │
│  • 작물 재배: 줄기 강도 변화 → 수경 재배 선호                               │
│                                                                             │
│  【 대기압 (0.6 kPa = 지구의 0.6%) 】                                        │
│  ───────────────────────────────────────────────────────────────────────    │
│  • 끓는점 저하: 물 끓는점 2°C → 저압 가공 시설 필요                         │
│  • 밀폐 필수: 모든 생산 시설 기밀 유지 → 건설 비용 +30%                     │
│  • 발효 환경: 저기압 발효 챔버 → 발효 속도 변화                             │
│  • 증발 가속: 수분 손실 빠름 → 밀폐 저장 필수                               │
│                                                                             │
│  【 기온 (-60°C 평균, -125°C ~ +20°C 변동) 】                                │
│  ───────────────────────────────────────────────────────────────────────    │
│  • 난방 필수: 생산 시설 상시 가온 → 기본 전력 소비                          │
│  • 냉각 불필요: 외부 환경이 냉각원 → 냉동 시설 비용 감소                    │
│  • 열팽창: 온도 변화 대응 설계 → 시설 내구도 영향                           │
│  • 발효 온도: 정밀 온도 제어 필수 → 발효실 에너지 소비 높음                 │
│                                                                             │
│  【 먼지 폭풍 (계절성) 】                                                    │
│  ───────────────────────────────────────────────────────────────────────    │
│  • 태양광 차단: 효율 -80% (수 Sol 지속)                                     │
│  • 외부 시설: 채굴/건설 작업 중단                                           │
│  • 장비 마모: 먼지 침투 → 유지보수 비용 증가                                │
│  • 통신 교란: 지구 교신 품질 저하                                           │
│                                                                             │
│  【 방사선 (지구의 2.5배) 】                                                 │
│  ───────────────────────────────────────────────────────────────────────    │
│  • 전자 장비: 차폐 필요 → 제어 칩셋 건설 비용 증가                          │
│  • 유기물 보호: 식품/종균 차폐 저장                                         │
│  • 돌연변이: 유산균 변이 가능성 → 연구 콘텐츠 연결                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
