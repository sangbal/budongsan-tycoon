## 8.1. 업적 디자인 철학

### 8.1.1. EARN 원칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      🏆 EARN: 업적 디자인 프레임워크                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  E - Earned (획득됨)                                                        │
│  ───────────────────────────────────────────────────────────────────────── │
│  • 시간을 투자하면 반드시 달성 가능해야 함                                  │
│  • 운에 의존하는 업적 최소화 (RNG 업적 ≤ 5%)                               │
│  • 달성 과정 자체가 플레이어의 성장을 보여줌                                │
│                                                                             │
│  A - Aspirational (열망을 자극)                                             │
│  ───────────────────────────────────────────────────────────────────────── │
│  • 달성하고 싶은 목표가 되어야 함                                           │
│  • 업적 이름과 설명이 매력적이어야 함                                       │
│  • 희귀 업적은 자랑할 가치가 있어야 함                                      │
│                                                                             │
│  R - Representative (대표성)                                                │
│  ───────────────────────────────────────────────────────────────────────── │
│  • 게임의 핵심 경험을 반영해야 함                                           │
│  • 다양한 플레이 스타일을 인정해야 함                                       │
│  • 진행 상황의 이정표 역할을 해야 함                                        │
│                                                                             │
│  N - Natural (자연스러움)                                                   │
│  ───────────────────────────────────────────────────────────────────────── │
│  • 일반 플레이 중 자연스럽게 달성 가능해야 함 (60%)                         │
│  • 의도적 도전 업적은 명확히 구분 (30%)                                     │
│  • 숨겨진 업적은 발견의 재미 제공 (10%)                                     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 8.1.2. 업적의 목적

```javascript
const ACHIEVEMENT_PURPOSE = {
  // 1차 목적: 성취감과 진행 피드백
  primary: {
    milestone_markers: '플레이어에게 진행 상황을 명확히 전달',
    accomplishment_feeling: '노력의 결과를 가시적으로 보상',
    skill_recognition: '숙련도 향상을 인정',
  },

  // 2차 목적: 컨텐츠 발견 유도
  secondary: {
    feature_discovery: '숨겨진 기능이나 전략 발견 유도',
    replayability: '다양한 플레이 방식 시도 동기 부여',
    completionism: '컬렉션 본능 자극으로 장기 플레이 유도',
  },

  // 3차 목적: 소셜 요소
  tertiary: {
    bragging_rights: '희귀 업적으로 자랑할 거리 제공',
    community_goals: '커뮤니티 공통 목표 생성',
    comparison: '친구와 진행 상황 비교 가능',
  },

  // 안티 패턴 (금지 사항)
  anti_patterns: [
    '재화 보상으로 P2W 유도',
    '극단적 그라인딩 강요 (1,000시간+)',
    '멀티플레이 필수 업적 (싱글 게임에서)',
    '버그나 글리치 악용 업적',
    '시간 제한 이벤트 전용 업적 (FOMO 유발)',
  ],
}
```

### 8.1.3. 스팀 스타일 순수 업적 원칙

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    📜 순수 업적 철학 (Pure Achievement Philosophy)           │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  "업적은 달성 자체가 보상이다"                                              │
│                                                                             │
│  ✅ 올바른 접근                                                              │
│  • 업적 = 자랑거리, 기록, 이정표                                            │
│  • 달성 시 팝업 알림 + 영구 기록                                            │
│  • 희귀 업적일수록 높은 명예                                                │
│  • 플랫폼(Steam/웹) 통합 달성률 표시                                        │
│                                                                             │
│  ❌ 피해야 할 접근                                                           │
│  • 업적 달성 → 재화 보상 (경제 밸런스 붕괴)                                 │
│  • 업적 달성 → 건물 해금 (업적 강제화)                                      │
│  • 업적 미달성 → 컨텐츠 잠금 (FOMO 유발)                                    │
│                                                                             │
│  🎯 예외 (허용되는 보상)                                                     │
│  • 칭호/타이틀 해금 (순수 장식)                                             │
│  • 프로필 배경 해금 (순수 장식)                                             │
│  • 블루프린트 스킨 해금 (기능 동일, 외형만 변경)                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

```javascript
const CONDITION_TYPES = {
  // 1. 카운터 (누적 달성)
  counter: {
    example: '김치 1,000개 생산',
    check: (stat, target) => getStatValue(stat) >= target,
    progress: (stat, target) => getStatValue(stat) / target,
  },

  // 2. 임계값 (순간 달성)
  threshold: {
    example: '$1,000,000 보유',
    check: (stat, target) => getCurrentValue(stat) >= target,
    progress: (stat, target) => getCurrentValue(stat) / target,
  },

  // 3. 이벤트 (특정 이벤트 발생)
  event: {
    example: '첫 프레스티지 완료',
    check: event_id => eventOccurred(event_id),
    progress: () => (eventOccurred() ? 1 : 0),
  },

  // 4. 복합 조건 (AND/OR)
  compound: {
    example: '6종 김치 모두 생산',
    check: (conditions, operator) => {
      if (operator === 'AND') {
        return conditions.every(c => checkCondition(c))
      } else if (operator === 'OR') {
        return conditions.some(c => checkCondition(c))
      }
    },
    progress: (conditions, operator) => {
      const completed = conditions.filter(c => checkCondition(c)).length
      return completed / conditions.length
    },
  },

  // 5. 지속 조건 (일정 시간 유지)
  sustained: {
    example: '병목 0개로 30분 유지',
    check: (condition, duration) => {
      return conditionMetForDuration(condition, duration)
    },
    progress: (condition, duration) => {
      return currentDuration(condition) / duration
    },
  },

  // 6. 부정 조건 (하지 않음)
  negative: {
    example: '전력 부족 없이 M5 도달',
    check: (anti_condition, target_event) => {
      return !eventOccurred(anti_condition) && eventOccurred(target_event)
    },
    progress: () => 0, // 진행률 표시 어려움
  },
}
```

```javascript
    case 'set':
      stats[key] = value
      break
```

```javascript
const ACHIEVEMENT_ENGINE = {
  // 활성 업적 목록 (아직 달성하지 않은 것)
  active_achievements: [],

  // 초기화
  init() {
    this.active_achievements = ALL_ACHIEVEMENTS.filter(a => !isUnlocked(a.id))
  },

  // 특정 통계 변경 시 체크
  checkForStat(category, key) {
    const relevantAchievements = this.active_achievements.filter(
      a => a.condition.stat === key || (a.condition.stats && a.condition.stats.includes(key))
    )

    relevantAchievements.forEach(a => this.checkAchievement(a))
  },

  // 개별 업적 체크
  checkAchievement(achievement) {
    const condition = achievement.condition
    let completed = false

    switch (condition.type) {
      case 'counter':
        completed = STATS_TRACKER.counters[condition.stat] >= condition.target
        break
      case 'threshold':
        completed = STATS_TRACKER.session[condition.stat] >= condition.target
        break
      case 'event':
        completed = STATS_TRACKER.discoveries[condition.event_id]
        break
      case 'compound':
        completed = this.checkCompoundCondition(condition)
        break
      // ... 기타 유형
    }

    if (completed) {
      this.unlockAchievement(achievement)
    }
  },

  // 업적 달성 처리
  unlockAchievement(achievement) {
    // 1. 상태 저장
    saveUnlock(achievement.id)

    // 2. 활성 목록에서 제거
    this.active_achievements = this.active_achievements.filter(a => a.id !== achievement.id)

    // 3. UI 알림
    showAchievementNotification(achievement)

    // 4. 분석 이벤트
    trackEvent('achievement_unlocked', {
      id: achievement.id,
      category: achievement.category,
      difficulty: achievement.difficulty,
      time_to_unlock: getPlaytime(),
    })

    // 5. 연쇄 체크 (마스터리 업적)
    this.checkMasteryAchievements(achievement.category)
  },

  // 주기적 체크 (초당 1회)
  periodicCheck() {
    // 지속 조건 업적 체크
    this.active_achievements
      .filter(a => a.condition.type === 'sustained')
      .forEach(a => this.checkSustainedCondition(a))
  },
}
```

## 8.7. 업적 밸런싱 및 테스트

### 8.7.1. 난이도 분포 목표

```javascript
const DIFFICULTY_DISTRIBUTION = {
  // 목표 분포 (난이도별 비율)
  target: {
    '⭐': 0.2, // 20% - 거의 모든 플레이어 달성
    '⭐⭐': 0.25, // 25% - 대부분 플레이어 달성
    '⭐⭐⭐': 0.3, // 30% - 중급 플레이어 달성
    '⭐⭐⭐⭐': 0.15, // 15% - 고급 플레이어 달성
    '⭐⭐⭐⭐⭐': 0.1, // 10% - 하드코어 플레이어만 달성
  },

  // 기대 달성률 범위
  expected_rates: {
    '⭐': { min: 0.7, max: 1.0 }, // 70-100%
    '⭐⭐': { min: 0.4, max: 0.7 }, // 40-70%
    '⭐⭐⭐': { min: 0.15, max: 0.4 }, // 15-40%
    '⭐⭐⭐⭐': { min: 0.03, max: 0.15 }, // 3-15%
    '⭐⭐⭐⭐⭐': { min: 0.001, max: 0.05 }, // 0.1-5%
  },

  // 현재 분포 검증
  validateDistribution(achievements) {
    const counts = {}
    achievements.forEach(a => {
      const diff = a.difficulty
      counts[diff] = (counts[diff] || 0) + 1
    })

    const total = achievements.length
    const warnings = []

    Object.entries(this.target).forEach(([diff, target]) => {
      const actual = (counts[diff] || 0) / total
      if (Math.abs(actual - target) > 0.05) {
        warnings.push(`${diff}: 목표 ${target * 100}%, 실제 ${(actual * 100).toFixed(1)}%`)
      }
    })

    return warnings
  },
}
```

```javascript
const ACHIEVEMENT_ANALYTICS = {
  // 실시간 달성률 추적
  trackUnlock(achievement_id, player_data) {
    analytics.track('achievement_unlocked', {
      achievement_id,
      difficulty: getAchievementDifficulty(achievement_id),
      category: getAchievementCategory(achievement_id),
      time_to_unlock: player_data.playtime,
      prestige_count: player_data.prestige_count,
      session_count: player_data.session_count,
    })
  },

  // 이상 탐지 규칙
  anomaly_detection: {
    // 너무 쉬운 업적 (예상보다 높은 달성률)
    too_easy: (expected, actual) => actual > expected * 1.5,

    // 너무 어려운 업적 (예상보다 낮은 달성률)
    too_hard: (expected, actual) => actual < expected * 0.5,

    // 빠른 달성 (예상 시간의 1/4 이하)
    too_fast: (expected_time, actual_time) => actual_time < expected_time * 0.25,

    // 치팅 의심 (불가능한 순서로 달성)
    cheat_suspect: unlock_sequence => {
      // M5 전에 M3 달성 필수 등 의존성 체크
      return !validateSequence(unlock_sequence)
    },
  },

  // 주간 리포트 생성
  generateWeeklyReport() {
    return {
      total_unlocks: getTotalUnlocksThisWeek(),
      most_unlocked: getTopAchievements(10),
      least_unlocked: getBottomAchievements(10),
      anomalies: detectAnomalies(),
      suggested_adjustments: suggestBalanceChanges(),
    }
  },
```
