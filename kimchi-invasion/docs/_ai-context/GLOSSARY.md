## 🎮 게임 용어

### 핵심 개념

| 용어           | 영문             | 설명                                             |
| :------------- | :--------------- | :----------------------------------------------- |
| **마일스톤**   | Milestone        | 게임 진행 단계 (M1~M5)                           |
| **프레스티지** | Prestige         | 우주선으로 새 행성 이주, 진행 리셋 + 영구 보너스 |
| **Loadout**    | Loadout          | 프레스티지 시 가져갈 기술 선택 시스템            |
| **메가베이스** | Megabase         | 엔드게임 대규모 공장 (SPM 1,000+)                |
| **SPM**        | Sushi Per Minute | 분당 김치 생산량 (엔드게임 지표)                 |

### 자원

| 용어                 | Tier | 설명                                                              |
| :------------------- | :--- | :---------------------------------------------------------------- |
| **원자재**           | 0    | 철광석, 얼음, 배추, 고추, 마늘                                    |
| **중간재**           | 1    | 철판, 물, 소금, 고춧가루, 다진마늘                                |
| **완제품**           | 2    | 김치 6종 (배추김치, 깍두기, 총각김치, 파김치, 오이소박이, 묵은지) |
| **🔬 유산균 데이터** | 3    | Tier 1-2 연구 자원                                                |
| **🧬 발효 배양액**   | 3    | Tier 3-4 연구 자원                                                |
| **🧫 오메가 종균**   | 3    | Tier 5 연구 자원                                                  |

### 건물 카테고리

| 용어     | 설명             | 예시                     |
| :------- | :--------------- | :----------------------- |
| **채굴** | 원자재 자동 수집 | 채굴기, 얼음 추출기      |
| **농업** | 작물 자동 재배   | 온실, 수경재배실         |

| **물류** | 자원 이동        | 컨베이어, 투입기, 드론   |
| **전력** | 에너지 공급      | 화력발전, 태양광, 핵융합 |
| **연구** | 기술 해금        | 연구소, 양자 연구소      |

## 🛠️ 기술 용어

### 아키텍처

| 용어           | 설명                                         |
| :------------- | :------------------------------------------- |
| **ECS**        | Entity-Component-System (게임 아키텍처 패턴) |
| **Tick Loop**  | 50ms 주기 물리 시뮬레이션                    |
| **Core Loop**  | 10-30분 주기 목표 달성 루프                  |
| **Flow State** | Csikszentmihalyi 이론 기반 몰입 상태         |

### 기술 스택

| 용어          | 설명                                |
| :------------ | :---------------------------------- |
| **PixiJS**    | 2D WebGL 렌더링 라이브러리          |
| **Zustand**   | 경량 상태 관리 라이브러리           |
| **Supabase**  | 오픈소스 Firebase 대안 (PostgreSQL) |
| **Howler.js** | 웹 오디오 라이브러리                |
| **i18next**   | 다국어 지원 프레임워크              |

### 배포

| 용어          | 설명                          |
| :------------ | :---------------------------- |
| **Phase 1**   | 웹 MVP (Vite)                 |
| **Phase 1.5** | Steam Early Access (Electron) |
| **Phase 2**   | Godot 4 리빌드                |
| **Phase 3**   | 멀티플랫폼 (Godot Export)     |
