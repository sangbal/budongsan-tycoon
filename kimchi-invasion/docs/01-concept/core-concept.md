```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    💰 화성-지구 경제 관계                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  【 화성 → 지구 수출 가치 】                                                │
│                                                                             │
│  화성 제품이 지구에서 프리미엄인 이유:                                      │
│                                                                             │
│  1. 희소성 (Scarcity)                                                       │
│     - 연간 수송 가능량 극히 제한                                            │
│     - "화성산" 라벨의 상징적 가치                                           │
│                                                                             │
│  2. 고유성 (Uniqueness)                                                     │
│     - 화성 환경에서만 가능한 발효 특성                                      │
│     - 지구에서 재현 불가능한 풍미                                           │
│                                                                             │
│  3. 스토리 (Narrative)                                                      │
│     - "인류 최초 화성 김치" 마케팅                                          │
│     - 수집가/미식가 타겟                                                    │
│                                                                             │
│  【 가격 체계 (게임 내 기준) 】                                             │
│                                                                             │
│  │ 품목              │ 화성 생산가 │ 지구 판매가 │ 마진율    │             │
│  ├───────────────────┼─────────────┼─────────────┼───────────┤             │
│  │ 기본 김치 (1kg)   │ $5          │ $500        │ 9,900%    │             │
│  │ 프리미엄 김치     │ $20         │ $2,000      │ 9,900%    │             │
│  │ 한정판 (100년 종균)│ $100       │ $50,000     │ 49,900%   │             │
│                                                                             │
│  ※ 운송비 별도. 화성-지구 화물 $10,000/kg                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```
