## 0.1. MVP 개요

### 0.1.1. 프로젝트 현황

| 항목            | 상태                       |
| --------------- | -------------------------- |
| **개발 체제**   | 1인 솔로 개발              |

## 0.2. MVP 포함 기능 (M1 + M2)

### 0.2.1. M1: 수동 단계 (MANUAL PHASE)

**예상 플레이 시간:** 1-2시간

#### 핵심 시스템

| 카테고리      | 기능        | 상세                           |
| ------------- | ----------- | ------------------------------ |
| **자원 수집** | 손 채굴     | 클릭으로 철광석, 얼음 수집     |
|               | 손 재배     | 클릭으로 배추, 마늘, 고추 수확 |
| **생산**      | 기초 용광로 | 철광석 → 철판 (수동)           |
|               | 절임 통     | 배추 + 소금 → 절인 배추 (수동) |
| **에너지**    | 화력 발전소 | 석탄 50kW                      |
| **물류**      | 수동 이동   | 드래그앤드롭 자원 이동         |
| **UI**        | 기본 HUD    | 자원 표시, 생산 상태           |
|               | 건설 메뉴   | 기초 건물 배치                 |

#### 해금 요소

```javascript
const M1_UNLOCKS = {
  buildings: [
    'hand_miner', // 손 채굴 (클릭 인터랙션)
    'hand_farm', // 손 재배 (클릭 인터랙션)
    'basic_furnace', // 기초 용광로
    'pickling_vat', // 절임 통
    'coal_generator', // 화력 발전소 (50kW)
  ],

  resources: [
    'iron_ore',
    'iron_plate',
    'coal',
    'ice',
    'water',
    'cabbage',
    'garlic',
    'chili',
    'salt',
    'pickled_cabbage',
  ],

  ui_features: ['basic_hud', 'build_menu', 'resource_panel', 'tutorial_overlay'],
}
```

#### 완료 조건

- [ ] 첫 김치 10캔 생산
- [ ] 기본 조작법 숙지 (튜토리얼 완료)

### 0.2.2. M2: 자동 채집 (AUTOMATION BEGINS)

**예상 플레이 시간:** 3-5시간 (누적 4-7시간)

#### 핵심 시스템

| 카테고리      | 기능          | 상세                  |
| ------------- | ------------- | --------------------- |
| **자원 수집** | 채굴기 Mk.I   | 자동 철광석/석탄 채굴 |
|               | 온실 Mk.I     | 자동 작물 재배        |
| **물류**      | 컨베이어 벨트 | 2 아이템/초           |
|               | 투입기        | 자동 아이템 투입      |
|               | 스플리터      | 물류 분배             |
| **연구**      | 연구소        | 기술 연구 시스템      |
| **생산**      | 발효 탱크     | 기초 발효 (자동)      |

#### 해금 요소

```javascript
const M2_UNLOCKS = {
  buildings: [
    'miner_mk1', // 채굴기 Mk.I
```

## 0.6. MVP 성공 기준

### 0.6.1. 정량적 기준

| 지표                | 목표             | 측정 방법            |
| ------------------- | ---------------- | -------------------- |
| **플레이 시간**     | 10-15시간 콘텐츠 | 내부 QA 플레이테스트 |
| **튜토리얼 완료율** | >80%             | 애널리틱스           |
| **M2 도달률**       | >50%             | 애널리틱스           |
| **크래시율**        | <1%              | Sentry 모니터링      |
| **로딩 시간**       | <5초             | 실기기 측정          |

### 0.6.2. 정성적 기준

| 항목            | 기준                                |
| --------------- | ----------------------------------- |
| **핵심 재미**   | "한 판만 더" 느낌이 드는가?         |
| **차별화**      | 김치 테마가 신선하게 느껴지는가?    |
| **학습 곡선**   | 튜토리얼 없이도 기본 조작 가능한가? |
| **최적화 욕구** | 공장 개선 아이디어가 떠오르는가?    |

## 0.7. 개발 우선순위

### 0.7.1. Phase 순서

```
Phase 1: 코어 시스템 (Week 1-4)
├── 타일맵 & 카메라
├── 건물 배치 시스템
├── 자원 시스템
└── 기본 UI

Phase 2: M1 콘텐츠 (Week 5-8)
├── 손 채굴/재배
├── 기초 생산 건물
├── 튜토리얼
└── 첫 김치 생산

Phase 3: M2 콘텐츠 (Week 9-12)
├── 컨베이어 벨트
├── 투입기 & 스플리터
├── 연구 시스템
└── 자동화 생산 라인

Phase 4: 폴리싱 (Week 13-16)
├── 오디오 통합
├── 밸런스 조정
├── 버그 수정
└── 최적화
```
