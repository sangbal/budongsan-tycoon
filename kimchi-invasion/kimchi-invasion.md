## 1. Core Concept & Narrative (세계관 및 핵심 가치)

### 1.1. 배경 스토리 (The Mission)

- **주인공:** 스페이스X 스타십을 타고 화성에 착륙한 첫 번째 한국인 바이오 엔지니어.
- **상황:** 화성 이주 초기, 대원들의 면역력 저하 해결을 위해 '김치 종균'을 활용한 김치 자체 생산 및 자동화 시스템 구축 수행.
- **최종 목표:** 화성 내 자체 필요한 김치를 생산하고, 남은 화성 김치를 지구로 역수출하여 막대한 자본($)을 벌어들이고, 우주선을 구매해 새로운 행성으로 도약.
- **슬로건:** "화성을 붉게 물들이는 것은 모래가 아니라 우리의 김치다."

### 1.2. 프레스티지 시스템 (Prestige & New Worlds)

#### 1.2.1. 프레스티지 개요

- **성간 이주:** 충분한 달러를 모아 지구에서 우주선 구매 시 새로운 행성으로 이주.
- **Loadout:** 해금한 **기술만** 선택적으로 가져감. 자원/건물은 매번 0부터 시작.
- **무한 랜덤 행성:** 매 프레스티지마다 새로운 랜덤 행성 생성.

#### 1.2.2. Loadout 시스템 (기술만)

| 우주선 등급 | Loadout 슬롯 | 비용       | 비고            |
| :---------- | :----------- | :--------- | :-------------- |
| **기본형**  | 3개          | $100,000   | 핵심 기술 3개만 |
| **중형**    | 5개          | $500,000   | 여유로운 선택   |
| **대형**    | 8개          | $2,000,000 | 거의 모든 기술  |

#### 1.2.3. 랜덤 행성 시스템

매 프레스티지마다 **자원 분포**가 랜덤으로 생성됩니다.

| 변수            | 범위        | 영향                    |
| :-------------- | :---------- | :---------------------- |
| **철광석 밀도** | 희소 ~ 풍부 | 공업 라인 속도          |
| **얼음 분포**   | 집중 ~ 분산 | 물/소금 확보 난이도     |
| **비옥도**      | 낮음 ~ 높음 | 작물 재배 속도          |
| **희귀 자원**   | 없음 ~ 풍부 | 핵연료/오메가 종균 확보 |
| **지형**        | 평탄 ~ 험준 | 건설 가능 면적          |

**행성 프리뷰:**

```

│                                                                             │

```

#### 1.2.4. 프레스티지 영구 보너스

프레스티지 횟수에 따라 **영구 보너스**가 누적됩니다.

| 프레스티지 횟수 | 보너스                            | 누적 효과 |
| :-------------- | :-------------------------------- | :-------- |
| 1회             | 생산 속도 +5%                     | +5%       |
| 2회             | 생산 속도 +5%                     | +10%      |
| 3회             | 생산 속도 +5%                     | +15%      |
| ...             | ...                               | ...       |
| 10회            | 특별 보너스: 시작 자금 +$1,000    | -         |
| 20회            | 특별 보너스: 무료 Loadout 슬롯 +1 | -         |

**최대 보너스:** 생산 속도 +100% (20회 프레스티지)

### 1.3. 디자인 철학

- **Low Floor:** 유치원생도 색깔과 도형(아이콘)만으로 시작할 수 있는 직관적 UX.
- **High Ceiling:** 전략 전문가가 자원 비율($Ratio$)과 물류 지연($Latency$)을 최적화하며 파고들 수 있는 데이터 깊이.

### 2.1.4. 시설 건설 비용 체계 ($ + 부품)

| 시설 등급      | 달러 ($) | 부품 요구               |
| :------------- | :------- | :---------------------- |
| **기초 시설**  | $만      | 철판 소량               |
| **중급 시설**  | $ + 부품 | 철판 + 배터리 셀        |
| **고급 시설**  | $ + 부품 | 철판 + 제어 칩셋 + 모터 |
| **업그레이드** | $ + 부품 | 해당 시설 부품 요구     |

**예시:**

- 온실 → 수경 재배실 업그레이드: $500 + 철판 ×10 + 제어 칩셋 ×2
- 컨베이어 벨트 → 고속 벨트: $200 + 철판 ×5 + 모터 ×1

### 2.1.5. 에너지 생산 체인 (3단계 진화)

| 단계     | 에너지원  | 재료/조건            | 출력 | 특징                   |
| :------- | :-------- | :------------------- | :--- | :--------------------- |
| **초기** | 석탄 발전 | 석탄 (소비)          | 낮음 | 자원 소모, 연기 발생   |
| **중기** | 태양광    | 철판 + 실리콘 (건설) | 중간 | 무료 전력, 낮에만 작동 |

**에너지 저장:** 메가팩 (배터리 셀 × 다수) → 밤 시간대 태양광 부족분 보충

### 2.1.6. 연구 자원 생산 체인 (Research Line)

### 2.3. 자동화 물류 상세 (Logistics Details)

- **컨베이어 벨트:** 대기 노출 시설 간 자원 이동 (2D 라인 아트).
- **진공 튜브:** 밀폐 필요 자원 이동 (식품 위생).

### 2.4. 전력망 (Energy System)

- **에너지 진화:** 석탄 (초기, 자원 소모) → 태양광 (중기, 무료/낮만) → 핵융합 (후기, 안정).
- **에너지 저장:** 메가팩으로 밤 시간대 전력 부족 해결.
- **전력 배선:** 전력 폴/변전소로 건물에 전력 공급 범위 설정.

| **플레이 스타일**   | 팩토리오 스타일 | 적극적 개입 필수, 배치/물류 설계가 핵심 |
| **세션 유형**       | 연속 플레이     | 시간 구분 없이 자유롭게 플레이          |
| **프레스티지 주기** | 10-20시간       | 하나의 행성에서 충분한 깊이             |
| **페널티 시스템**   | 초기: 샌드박스  | 추후 업데이트로 페널티 추가 예정        |

### 4.2. Multi-layer Loop 구조

```
┌─────────────────────────────────────────────────────────────────┐
│ META LOOP (10-20시간)                                           │
│  └─ 전체 진행 → 우주선 완공 → Loadout 선택 → 새 행성            │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │ SESSION LOOP (1-3시간)                                   │   │
│   │  └─ 마일스톤 달성 → 기술 해금 → 공장 확장                │   │
│   │                                                         │   │
│   │   ┌─────────────────────────────────────────────────┐   │   │
│   │   │ CORE LOOP (5-15분)                              │   │   │
│   │   │  └─ 생산라인 구축 → 병목 발견 → 최적화          │   │   │
│   │   │                                                 │   │   │
│   │   │   ┌─────────────────────────────────────────┐   │   │   │
│   │   │   │ MICRO LOOP (수 초)                      │   │   │   │
│   │   │   │  └─ 배치 → 연결 → 피드백                │   │   │   │
│   │   │   └─────────────────────────────────────────┘   │   │   │
│   │   └─────────────────────────────────────────────────┘   │   │
│   └─────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### 4.3. Micro Loop (수 초 단위)

| 요소            | 방식        | 설명                                           |
| :-------------- | :---------- | :--------------------------------------------- |
| **배치**        | 그리드 배치 | 팩토리오 스타일 정밀 그리드 시스템             |
| **병목 시각화** | 아이템 적체 | 벨트 위 아이템이 쌓이는 것을 시각적으로 표현   |
| **자원 이동**   | 실시간 이동 | 아이템이 벨트 위를 실제로 이동 (시각적 만족감) |

### 4.4. Core Loop (5-15분 사이클)

```
┌──────────────────────────────────────────────────────────────────┐
│  1. 목표 수령                                                    │
│     └─ 화성 내부 미션 (Phase 1) 또는 지구 수출 계약 (Phase 2)    │
│                                                                  │
│  2. 자원 확보                                                    │
│     └─ 채굴/재배를 통한 원재료 수급                              │
│                                                                  │
│  3. 생산 라인 구축                                               │
│     └─ 레시피 기반 가공 시설 배치 및 연결                        │
│                                                                  │
│  4. 병목 발견                                                    │
│     └─ 아이템 적체 시각화로 문제 지점 파악                       │
│                                                                  │
│  5. 최적화                                                       │
│     └─ 라인 재설계, 스플리터 추가, 병렬화                        │
│                                                                  │
│  6. 목표 달성 → 보상                                             │
│     └─ 달러($) (김치 → 분석기 → 유산균 데이터로 연구 자원 생산)  │
└──────────────────────────────────────────────────────────────────┘
```

### 4.5. 목표 시스템 (2단계 계약)

| Phase       | 이름           | 설명                                   | 보상                |
| :---------- | :------------- | :------------------------------------- | :------------------ |
| **Phase 1** | 화성 내부 수급 | 대원들의 생존을 위한 김치 생산 미션    | 건설 자재 (철판 등) |
| **Phase 2** | 지구 역수출    | Phase 1 안정화 후 해금. 지구 주문 수주 | 달러($)             |

- **Phase 1 예시:** "대원 10명을 위해 김치 50캔 생산" → 보상: 철판 ×20
- **Phase 2 예시:** "지구 주문: 프리미엄 김치 500캔 / 마감: 30분" → 보상: $5,000

### 4.6. 경제 시스템

| 자원 유형     | 용도                               | 획득 방법                             |
| :------------ | :--------------------------------- | :------------------------------------ |
| **달러 ($)**  | 건물/장비 구매, 업그레이드, 우주선 | 지구 수출 계약 완료                   |
| **연구 자원** | 기술 연구 해금                     | 김치 생산 → 분석기/배양기/고급 연구실 |

> 💡 **핵심 변화:** 연구 자원은 미션 보상이 아닌 **생산 라인**에서 직접 생산합니다.
> 더 많은 기술을 빨리 해금하려면 → 더 많은 김치를 생산 → 분석기에 투입 → 유산균 데이터 확보

## 5. 온보딩 & 튜토리얼 (Onboarding System)

### 5.1. 온보딩 철학

- **스토리 기반:** 대원들의 요청에 따라 자연스럽게 시스템 학습
- **목표 시간:** 10-15분 (핵심 메카닉 습득 후 자유 플레이)
- **저항감 최소화:** 텍스트 최소화, 애니메이션과 하이라이트로 유도

### 5.2. 튜토리얼 시퀀스 (Story-driven)

#### 프롤로그: 착륙 (30초)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  🚀 [컷씬] 스타십이 화성에 착륙                                              │
│                                                                             │
│  "화성 착륙 완료. 당신은 바이오 엔지니어로서                                 │
│   대원들의 건강을 책임지게 되었습니다."                                      │
│                                                                             │
│  [지휘 센터 자동 배치됨]                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 1단계: 수동 자원 수집 (2분)

| 대원 요청          | 학습 내용                         | 보상   |
| :----------------- | :-------------------------------- | :----- |
| "물이 필요합니다!" | 얼음 노드 클릭 → 손으로 얼음 수집 | 물 ×10 |
| "흙이 필요합니다!" | 흙 노드 클릭 → 손으로 흙 수집     | 흙 ×10 |

**핵심 학습:** 자원 노드 클릭 = 수동 채집

#### 2단계: 첫 번째 건물 (2분)

| 대원 요청                               | 학습 내용                       | 보상        |
| :-------------------------------------- | :------------------------------ | :---------- |
| "채굴기를 설치하면 자동으로 수집됩니다" | 건물 메뉴 열기 → 채굴기 배치    | 채굴기 해금 |
| "얼음 위에 해동기를 설치하세요"         | 해동기 배치 → 물 자동 생산 확인 | 해동기 해금 |

**핵심 학습:** 건물 배치 = 자동화

#### 3단계: 첫 번째 작물 (3분)

| 대원 요청                | 학습 내용                           | 보상             |
| :----------------------- | :---------------------------------- | :--------------- |
| "배추를 재배해야 합니다" | 온실 배치 → 배추씨앗 + 흙 + 물 투입 | 배추 ×5          |
| "양념 재료도 필요합니다" | 두 번째 온실 → 고추/마늘 재배       | 고추 ×5, 마늘 ×5 |

**핵심 학습:** 레시피 개념 (입력 → 건물 → 출력)

#### 4단계: 물류 연결 (3분)

| 대원 요청                       | 학습 내용                     | 보상        |
| :------------------------------ | :---------------------------- | :---------- |
| "자원을 자동으로 옮겨야 합니다" | 컨베이어 벨트 배치, 건물 연결 | 벨트 ×20    |
| "투입기로 건물에 넣어주세요"    | 투입기 배치 → 자동 투입 확인  | 투입기 해금 |

**핵심 학습:** 벨트 + 투입기 = 자동 물류

#### 5단계: 첫 번째 김치! (3분)

| 대원 요청                         | 학습 내용                          | 보상               |
| :-------------------------------- | :--------------------------------- | :----------------- |
| "드디어 김치를 만들 수 있습니다!" | 절임소 → 배합기 → 발효실 라인 구축 | 첫 김치 생산!      |
| "대원들에게 김치를 배급하세요"    | 김치 드래그 → 지휘 센터            | 튜토리얼 완료 보상 |

**핵심 학습:** 복잡한 생산 라인 구축

#### Row Level Security (RLS)

```sql
-- 본인 데이터만 읽기/쓰기
ALTER TABLE game_saves ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage own saves"
  ON game_saves FOR ALL
  USING (auth.uid() = user_id);

-- 리더보드는 전체 읽기, 본인만 쓰기
ALTER TABLE leaderboard ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Anyone can read leaderboard"
  ON leaderboard FOR SELECT USING (true);

CREATE POLICY "Users can update own score"
  ON leaderboard FOR ALL
  USING (auth.uid() = user_id);
```

### 10.6. 기술 구현

#### Howler.js 설정

```typescript
// 오디오 매니저 구조
interface AudioManager {
  // BGM 레이어 (동시 재생)
  bgmLayers: {
    ambient: Howl // 항상 재생
    activity: Howl // 활동 시
    tension: Howl // 긴장 상황
    achievement: Howl // 성취 시
  }

  // SFX 풀 (인스턴스 재사용)
  sfxPool: Map<string, Howl[]>

  // 환경음 (루프)
  ambience: {
    mars: Howl
    factory: Howl
  }

  // 볼륨 컨트롤
  volumes: {
    master: number
    bgm: number
    sfx: number
    ambience: number
    ui: number
  }
}
```

#### 오디오 파일 형식

| 용도       | 형식      | 비트레이트 | 이유                   |
| :--------- | :-------- | :--------- | :--------------------- |
| **BGM**    | OGG + MP3 | 128kbps    | 파일 크기 vs 품질 균형 |
| **SFX**    | OGG + MP3 | 96kbps     | 짧은 클립, 빠른 로딩   |
| **환경음** | OGG       | 64kbps     | 긴 루프, 저용량 필요   |
